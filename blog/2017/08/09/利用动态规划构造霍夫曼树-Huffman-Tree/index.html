霍夫曼树

　　给定n个权值作为n个叶子结点，构造一棵二叉树，若带权路径长度达到最小，称这样的二叉树为最优二叉树(Optimal Binary Search Tree)，也称为哈夫曼树(Huffman Tree)。哈夫曼树是带权路径长度最短的树，权值较大的结点离根较近。

最优二叉搜索树问题

　　给定n个不同关键字的已排序的序列\(K=<k_1,k_2,...,k_n>（k_1<k_2<...<k_n）\)，我们想从这些关键字中构造一棵二叉查找树。对每个关键字\(k_i\)，一次搜索搜索到的概率为\(p_i\)。可能有一些搜索的值不在\(K\)内，因此还有\(n+1\)个“伪关键词”\(d_0,d_1,...,d_n\)，它们代表不在\(K\)内的值。具体：\(d_0\)代表所有小于\(k_1\)的值，\(d_n\)代表所有大于\(k_n\)的值。而对于\(i=1,2,...,n-1\)，伪关键词\(d_i\)代表所有位于\(k_i\)和\(k_{i+1}\)之间的值。对于每个伪关键词，一次搜索对应于\(d_i\)的概率为\(q_i\)。下图展示了对一个n=5个关键词的集合构造的两棵二叉搜索树。

　　每个关键字\(k_i\)是一个内部结点，而每个伪关键词\(d_i\)是一个叶结点，每次搜索要么找到某个关键词\(k_i\)成功，要么找到某个伪关键词\(d_i\)失败，因此有如下公式。

\[ \sum_{i=1}^n p_i + \sum_{i=0}^n q_i = 1 \]

　　要使得查找一个节点的期望代价最小，就需要建立一棵最优二叉查找树。期望代价可以通过这个公式算得。

\[ \begin{align} E[search \ cost \ in \ T] & = \sum_{i=1}^n (depth_T(k_i)+1)\cdot p_i + \sum_{i=0}^n (depth_T(d_i)+1)\cdot q_i \\ & = 1 + \sum_{i=1}^n depth_T(k_i)\cdot p_i + \sum_{i=0}^n depth_T(d_i)\cdot q_i \end{align} \]

　　假设给出\(n=5\)的关键词集合的搜索概率如下

\[ \begin{array}{c|lcr} i & 0 & 1 & 2 & 3 & 4 & 5 \\ \hline p_i & 0 & 0.15 & 0.10 & 0.05 & 0.10 & 0.20 \\ \hline q_i & 0.05 & 0.10 & 0.05 & 0.05 & 0.05 & 0.10 \end{array} \]

　　那么(a)树的搜索代价为2.80，(b)树的搜索代价为2.75，(b)树实际上也就是霍夫曼树。最优二叉树不一定是高度最矮的，概率最高的关键字也不一定出现在根结点。 最优二叉搜索树问题就是要求构造一棵期望搜索代价最小的二叉搜索树，如果我们穷举的话，它的时间效率是指数级的，显然不能接受，所以需要用动态规划解决这个问题。

最优二叉搜索树的结构

　　要想使用动态规划解决这个问题，我们需要找出子问题的最优结构，所以为了刻画最优二叉搜索树的结构，我们从观察子树特征开始。考虑一棵二叉搜索树的任意子树，因为\(K=<k_1,k_2,...,k_n>\)是有序的，所以它必须包含连续关键字\(k_i,...,k_j, 1 \le i \le j \le n\)，而且其叶子结点必然是伪关键字\(d_{i-1},...,d_j\)。
　　那么，我们现在便可以给出二叉搜索树的最优子结构：如果一棵最优二叉搜索树\(T\)有一棵包含关键字\(k_i,...,k_j\)的子树\(T'\)，那么\(T'\)必然是包含关键字\(k_i,...,k_j\)和伪关键字\(d_{i-1},...,d_j\)的子问题的最优解。
　　这样我们便可以利用子问题的最优解来构造原问题的最优解。个定关键字\(k_i,...,k_j\)，其中某个关键字，比如说\(k_r(i \le r \le j)\)，是这些关键字的最优子树的根结点。那么\(k_r\)的左子树就包含关键字\(k_i,...,k_{r-1}\)（和伪关键字\(d_{i-1},...,d_{r-1}\)），而右子树包含关键字\(k_{r+1},...,k_j\)(和伪关键字\(d_r,...,d_j\))。只要我们检查所有的根结点\(k_r(i \le r \le j)\)，并对每种情况分别求解包含\(k_i,...,k_{r-1}\)以及包含\(k_{i+1},...,k_j\)的最优二叉搜索树，即可保证找到原问题的最优解。
　　还需要注意空子树的问题，假定包含\(k_i,...,k_j\)子问题，我们选定\(k_i\)为根结点，根据前面所说的\(k_i\)的左子树包含\(k_i,...,k_{i-1}\)，这时我们将这个序列解释为不包含任何关键字。但是，子树仍然包含单一伪关键字\(d_{i-1}\)，对称的，如果\(k_j\)作为根结点的话，\(k_j\)的右子树也不包含任何关键字，但是包含单一伪关键字\(d_j\)。

递归解

　　接下来，我们来给出递归式。我们定义\(e[i,j]\)为在包含关键字\(k_i,...,k_j\)的最优二叉搜索树中进行一次搜索的期望代价。
　　需要注意的是\(j\)的取值范围是\(j \ge i-1\)，因为当\(j=i-1\)的时候，子树只有一个结点，也就是伪关键字\(d_{i-1}\)，不包含任何关键字，所以\(e[i,i-1]=q_{i-1}\)。当\(j \ge i\)时，我们选中一个根结点\(k_r\)，左子树为\(k_i,...,k_{r-1}\)，右子树为\(k_r(i \le r \le j)\)，当一棵子树成为一个结点的子树时，每个结点的深度都会加1，由下面这个公式：

\[ \begin{align} E[search \ cost \ in \ T] & = \sum_{i=1}^n (depth_T(k_i)+1)\cdot p_i + \sum_{i=0}^n (depth_T(d_i)+1)\cdot q_i \\ & = 1 + \sum_{i=1}^n depth_T(k_i)\cdot p_i + \sum_{i=0}^n depth_T(d_i)\cdot q_i \end{align} \]

　　可以看出，这棵子树的期望搜索代价的增加值应该为所有概率之和，对于包含关键字\(k_i,...,k_j\)的子树，所有概率之和为：

\[ w(i,j)=\sum_{l=i}^jp_l + \sum_{l=i-1}^jq_l \]

　　因此，我们可以写出：

\[ e[i,j]=p_r+(e[i,r-1]+w(i,r-1))+(e[r+1,j]+w(r+1,j)) \]

　　又因为：

\[ w(i,j)=w(i,r-1)+ p_r + w(r+1,j) \]

　　所以：

\[ e[i,j]=e[i,r-1]+e[r+1,j]+w(i,j) \]

　　最终我们得到递归公式：

\[ e[i,j] = \begin{cases} q_{i-1}, & {j=i-1} \\ \min_{i \le r \le j}\{e[i,r-1]+e[r+1,j]+w(i,j)\}, & {i \le j} \end{cases} \]

　 此外我们还需要定义\(root[i,j]\)来保存根结点\(k_r\)的下标\(r\)。

动态规划的自底向下计算最优二叉搜索树的期望搜索代价

　　有了递归式之后，代码就很容易实现，下面是Java代码。

    double getOptimalBST(int n, double[] p, double[] q) {
        double[][] e = new double[n + 2][n + 1];
        double[][] w = new double[n + 2][n + 1];
        int[][] root = new int[n + 1][n + 1];

        for (int i = 1; i <= n + 1; i++) {
            e[i][i - 1] = q[i - 1];
            w[i][i - 1] = q[i - 1];
        }

        for (int l = 1; l <= n; l++) {
            for (int i = 1; i <= n - l + 1; i++) {
                int j = i + l - 1;
                e[i][j] = Double.MAX_VALUE;
                w[i][j] = w[i][j - 1] + p[j] + q[j];
                for (int r = i; r <= j; r++) {
                    double temp = e[i][r - 1] + e[r + 1][j] + w[i][j];
                    if (e[i][j] > temp) {
                        e[i][j] = temp;
                        root[i][j] = r;
                    }
                }
            }
        }
        printRoots(root, 1, n, 1);

        return e[1][n];
    }

　　分析一下它的时间复杂度，它包含了三重循环，它的时间复杂度是\(O(n^3)\)。

构造解

　　接下来，得到了最优搜索代价后，其实与之对应的，其实我们的最优搜索二叉数也相应的建造好了，因为我们的算法中，把\(i,...,j\)的根节点保存到了\(root[i][j]\)里，只要我们调用递归函数，递归的打印出根结点和它们的左右结点就可以了，构造树也是一个道理，只不过把输出操作换成了建树操作，下面是打印的代码。

    private int printRoots(int[][] root, int i, int j, int level) {
        if (i > j) return 0;
        int r = root[i][j];
        int left = printRoots(root, i, r - 1, level + 1);
        int right = printRoots(root, r + 1, j, level + 1);
        System.out.println("level: " + level +
                " root: k" + r + " " +
                "left: " + (left == 0 ? "None" : "k" + left) + " " +
                "right: " + (right == 0 ? "None" : "k" + right));

        return r;
    }

　　按照上面的那个例子，输出结果为：

level: 2 root: k1 left: None right: None
level: 4 root: k3 left: None right: None
level: 3 root: k4 left: k3 right: None
level: 2 root: k5 left: k4 right: None
level: 1 root: k2 left: k1 right: k5

　　结果完全正确。
