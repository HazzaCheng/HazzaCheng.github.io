问题定义

　　**最长公共子序列问题(longest-common-subsequence problem)**是指给定两个序列\(X=\lt x_1,x_2,...,x_m\gt\)和\(Y=\lt y_1,y_2,...,y_n\gt\)，求\(X\)和\(Y\)的最长的公共子序列。

公共子序列(common subsequence)的概念
In mathematics, a subsequence is a sequence that can be derived from another sequence by deleting some elements without changing the order of the remaining elements. For example, the sequence \(\lt A,B,D\gt\) is a subsequence of \(\lt A,B,C,D,E,F\gt\) obtained after removal of elements \(C\),\(E\) and \(F\).The relation of one sequence being the subsequence of another is a preorder.
The subsequence should not be confused with substring \(\lt A,B,C,D \gt\), which can be derived from the above string \(\lt A,B,C,D,E,F \gt\) by deleting substring \(\lt E,F\gt\). The substring is a refinement of the subsequence.
Given two sequences \(X\) and \(Y\), a sequence \(Z\) is said to be a common subsequence of \(X\) and \(Y\), if \(Z\) is a subsequence of both \(X\) and \(Y\). For example, if
\(\lt X=\langle A,C,B,D,E,G,C,E,D,B,G \gt\) and
\(\lt Y=\langle B,E,G,C,F,E,U,B,K \gt\)
then a common subsequence of \(X\) and \(Y\) could be
\(\lt Z=B,E,E \gt\)
This would not be the longest common subsequence, since \(Z\) only has length 3, and the common subsequence \(\lt B,E,E,B \gt\) has length 4. The longest common subsequence of X and Y is \(\lt B,E,G,C,E,B \gt\).

LCS的最优子结构

　　如果用暴力法解决LCS问题，对于长度为\(m\)的序列，它有\(2^m\)个子序列，因此暴力查询的运行时间是指数阶，显然是不可取的。
　　但是LCS问题是具有最优子结构性质的，子问题的自然分类对应两个输入序列的＂前缀＂对，下面我们将来阐述这个定理。
　　首先，我们给出前缀的严谨定义，给定一个序列\(X=\lt x_1, x_2,...,x_m \gt\)，对\(i=0,1,...,m\)，定义\(X\)的前缀为\(X_i=\lt x_1, x_2,...,x_i \gt\)。
　　令\(X=\lt x_1, x_2,...,x_m \gt\)和\(Y=\lt y_1, y_2,...,y_n \gt\)为两个序列，\(Z=\lt z_1, z_2,...,z_k \gt\)为\(X\)和\(Y\)的任意LCS。

  1. \(如果x_m=y_n，则z_k=x_m=y_n且Z_{k-1}是X_{k-1}和Y_{k-1}的一个LCS。\)
  2. \(如果x_m \neq y_n，则z_k \neq x_m意味着Z是X_{m-1}和Y的一个LCS。\)
  3. \(如果x_m \neq y_n，则z_k \neq y_n意味着Z是X和Y_{n-1}的一个LCS。\)

　　具体的证明，这里就不给出了。

递归解

　　由上面的定理得知，在求解\(X=\lt x_1, x_2,...,x_m \gt\)和\(Y=\lt y_1, y_2,...,y_n \gt\)的一个LCS时，我们需要解一个或两个子问题，如果\(x_m = y_n\)，我们应该求解\(X_{m-1}\)和\(Y_{n-1}\)的一个LCS。将\(x_m = y_n\)追加到这个LCS的末尾，就会得到\(X\)和\(Y\)的一个LCS。如果\(x_m \neq y_n\)，我们需要求解两个子问题，\(X_{m-1}\)和\(Y\)的一个LCS和\(X\)和\(Y_{n-1}\)的一个LCS，两个LCS较长的一个即成为\(X\)和\(Y\)的一个LCS。由于这些情况覆盖了所有可能性，因此我们知道必然有一个子问题的最优解出现在\(X\)和\(Y\)的LCS中。
　　我们很容易的看出LCS问题的重叠子问题性质，我们建立最优解的递归式，我们定义\(c[i,j]\)表示\(X_i\)和\(Y_j\)的LCS长度。

\[ c[i,j] = \begin{cases} 0, & {i = 0或j = 0} \\ c[i-1,j-1]+1 & {i,j>0且x_i=y_j} \\ \max(c[i,j-1],c[i-1,j]), & {i,j>0且x_i \neq y_j} \end{cases} \]

动态规划的自底向下计算LCS长度

　　按照上面的思路，很容易实现算法返回LCS的长度，但是我们怎么保存LCS呢，我们可以看看下面这张图。

　　在我们的算法中按行主次序，计算表项，即首先由从左到右计算c的第一行，然后是第二行，所以我们可以用指向左上方的箭头，左边的箭头和上方的箭头来表示LCS，在程序中的b数组里，我们用1表示指向左上方的箭头，2表示指向左边的箭头，3表示指向上方的箭头，具体代码如下：

    public int getLCSlen(char[] x, char[] y) {
        int lenX = x.length, lenY = y.length;
        int[][] c = new int[lenX + 1][lenY + 1];
        int[][] b = new int[lenX + 1][lenY + 1];
        for (int i = 0; i < lenX; i++) {
            for (int j = 0; j < lenY; j++) {
                c[i][j] = 0;
                b[i][j] = 0;
            }
        }

        for (int i = 1; i <= lenX; i++) {
            for (int j = 1; j <= lenY; j++) {
                if (x[i - 1] == y[j - 1]) {
                    c[i][j] = c[i - 1][j - 1] + 1;
                    b[i][j] = 1;    // 1 means pointing the top left
                } else if (c[i - 1][j] > c[i][j - 1]) {
                    c[i][j] = c[i - 1][j];
                    b[i][j] = 2;    // 2 means pointing the top
                } else {
                    c[i][j] = c[i][j - 1];
                    b[i][j] = 3;    // 3 means pointing the left
                }
            }
        }
        printLCS(b, x, lenX, lenY);
        System.out.println();
        return c[lenX][lenY];
    }

　　知道了递归式之后，代码也很容易实现，我们考虑下时间复杂度，为\(O(mn)\)，因为每个表相的计算时间为\(O(1)\)，时间效率较暴力法已经大大提升了。

构造LCS

　　我们可以用上述算法中的\(b\)数组快速构造LCS，只需递归的调用函数，从\(b[lenX][lenY]\)开始知道\(i==0\)或\(j==0\)即可，时间复杂度在\(O(m+n)\)左右。

    private void printLCS(int[][] b, char[] x, int i, int j) {
        if (i == 0 || j == 0) return;
        if (b[i][j] == 1) {
            printLCS(b, x, i - 1, j - 1);
            System.out.print(x[i - 1] + " ");
        }
        else if (b[i][j] == 2) printLCS(b, x, i - 1, j);
        else printLCS(b, x, i, j - 1);
    }

空间优化

　　在空间上，我们还可以做出一些优化，例如对于LCS算法，\(b\)表是不需要的，每个\(c[i,j]\)只依赖于表中的\(c[i,j-1]\)，\(c[i-1,j]\)和\(c[i-1,j-1]\)。给定\(c[i,j]\)的值，我们可以在\(O(1)\)时间内计算出\(c[i,j]\)用了哪一项，总的重构LCS的时间依然是\(O(m+n)\)，但是节省了空间开销，算法如下。

    private void printLCS2(int[][] c, char[] x, char[] y, int i, int j) {
        if (i == 0 || j == 0) return;
        if (x[i - 1] == y[j - 1]) {
            printLCS2(c, x, y, i - 1, j - 1);
            System.out.print(x[i - 1] + " ");
        }
        else if (c[i - 1][j] >= c[i][j - 1]) printLCS2(c, x, y, i - 1, j);
        else printLCS2(c, x, y, i, j - 1);
    }

　　同样\(c\)表也可以节省开支，因为在任意时刻LCS算法只需要\(c\)表中的两行，即当前一行和前一行，但是缩小了\(c\)表的空间开销后，我们便不能在\(O(m+n)\)时间内完成LCS的重构工作。
