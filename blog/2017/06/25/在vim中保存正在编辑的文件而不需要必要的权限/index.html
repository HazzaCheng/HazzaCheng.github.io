在vim中保存正在编辑的文件而不需要必要的权限

2017-06-25 阅读时长: 2 分钟

引言

　　在使用linux用vim编辑文件的过程中，我们会经常忘记加sudo，因此有些文件就因为权限问题不能修改,你又不想半途而废，退出vim重新编辑，这时你就可以这条命令，做到不退出也可以保存编辑的内容：

:w !sudo tee %

　　这个命令整的语法是这样的：

:[range]w[rite] [++opt] !{cmd}
Execute {cmd} with [range] lines as standard input,(note the space in front of the '!').  {cmd} is executed like with ":!{cmd}", any '!' is replaced with the previous command |:!|.

　　一开始，我也十分不理解这个命令，通过查阅资料，来做一些解释。
　　主要参考自How does the vim “write with sudo” trick work?

理解％

　　首先我们来理解下这里的％是什么意思，％其实是表示当前文件名的意思，在vim中％的另外一个使用是文字替代的功能，例如：

:%s/aaa/bbb

　　这条命令表示的是就是把当前文件内的所有"aaa"替换成＂bbb＂。

理解:W

　　你可能理解：w是修改了你的当前文件，但实际上是不是的，例如这个命令：

:w temp.txt

　　执行这个命令，你可以理解为是另存为文件temp.txt的意思，它对你当前打开的文件并没有造成修改，而是把当前你修改的内容写到temp.txt中. 同样，你不仅可以把内容写到一个文件中，也可以将内容传到一个shell command里,例如：

:w !cat

　　这个命令只会把内容显示到终端上，如果vim没有用sudo权限运行的话，理所当然:W不能保存一个文件，但是如果它把修改内容传给shell,一个shel里的命令可以用sudo权限，在这个例子里我们用的是tee。

理解tee

　　tee这个命令大家应该都很熟悉，读取标准输入的数据，并将其内容输出成给定文件和屏幕上,当作下一个管道命令的数据源。
　　例如一下这个命令：

ls | tee out.txt | grep ".*txt"

　　ls的内容不仅保存到out.txt中，还被grep后输出到屏幕了。
　　所以tee %这个命令是把修改的内容又写到了当前文件中，我们只需要写到文件，实际上内容也输出到了stdout上，但是我们不需要，当然我们也可以tee % > /dev/null，不把它输出stdout上 所以这就可以看作是保存文件的一个代替方法，因为我们可以获得sudo权限。

技巧

　　我们可以在.vimrc中，添加：

" Allow saving of files as sudo when I forgot to start vim using sudo.
cmap w!! w !sudo tee > /dev/null %

　　下次执行w!! 这个命令就可以强制保存啦！
