最大子数组问题(The maximum-subarray problem)

问题描述

　　我们首先看《算法导论》里的一个例子，如下图所示，它描述了一支股票的价格浮动情况。
　　我们直观的可能认为，在股票价格最低的时候买入，和价格最高的时候卖出，我们会获得最大的利润，但是如下图的例子所示，事情不是我们直观的想的那样。
　　为了获得最大的利润，我们需要在2买入，在3卖出，两个点都不是最低和最高的时候。
　　因此我们实际上可以把这个问题模型简化，我们的目的是寻找出一段时期，使得它在这段时期内的，股票价格净值变化最大，因此我们就可以构造出如下图所示的一个数组\(A\)，它给出了每日股票价格较前一天的变化。
　　这样问题就简化为寻找\(A\)中的和最大的非空连续子数组，我们称这样的连续子数组为最大子数组(maximum subarray)，注意这个数组中一定要有负值，否则全是正值的话，对数组求和最大子数组就没有意义了，因为最大子数组一定是整个数组。
　　想要用暴力的方法解决这个问题是非常容易的，我们只需要用两层循环，在\(O(n^2)\)的时间复杂度之内就可以完成。
　　那么我们如何高效的解决这个问题，接下来介绍分治策略和动态规划两种方法。

分治策略

　　假定我们需要寻找子数组\(A[low..high]\)的最大子数组，使用分治策略意味着我们要将子数组划分为两个规模尽量相等的子数组，也就是找到子数组的中央位置，记为\(mid\)，然后求解两个子数组\(A[low..mid]\)和\(A[mid+1..high]\)。
　　这样也带来个问题，如下图所示，\(A[low..high]\)的任意子数组\(A[i..j]\)所处的位置必然是这三种情况之一：

  • 完全位于子数组\(A[low..mid]\)中，因此\(low \le i \le j \le mid\)。
  • 完全位于子数组\(A[mid+1..high]\)中，因此\(mid \lt i \le j \le high\)。
  • 跨越了中点，因此\(low \le i \le mid \lt j \le high\)。

　　前两种情况都很好解决，第三种情况有点棘手，但是仔细想想，如下图所示，我们其实把这种情况的子数组，看成是由形如\(A[i..mid]\)和\(A[mid+1..j]\)组成的，其中此\(low \le i \le mid\)且\(mid \lt j \le high\)，我们只需要找出\(A[i..mid]\)和\(A[mid+1..j]\)的最大子数组，然后将它们合并就可以了，需要注意的是\(mid\)和\(mid+1\)必须被各自包含在两个子数组中，否则无法形成一个连续的数组。
　　具体的Java代码实现如下：

Java代码实现

    /**
     * Find the maximum sub array.
     * @param A The input array.
     * @param low The start index of the sub array.
     * @param high The end index of the sub array.
     * @return An int array includes the start index of the maximum sub array,
     *         the end index of the maximum sub array and the sum of maximum sub array.
     */
    int[] findMaximumSubarray(int[] A, int low, int high) {
        if (low == high) return new int[]{low, high, A[low]};

        int mid = (low + high) / 2;
        int[] left = findMaximumSubarray(A, low, mid);
        int[] right = findMaximumSubarray(A, mid + 1, high);
        int[] cross = findMaxCrossingSubarray(A, low, mid, high);

        if (left[2] >= right[2] && left[2] >= cross[2]) return left;
        else if (right[2] >= left[2] && right[2] >= cross[2]) return right;
        else return cross;
    }

    /**
     * Find the maximum crossing sub array.
     * @param A The input array.
     * @param low The start index of the sub array.
     * @param mid The mid index of the sub array.
     * @param high The end index of the sub array.
     * @return An int array includes the start index of the maximum sub array,
     *         the end index of the maximum sub array and the sum of maximum sub array.
     */
    int[] findMaxCrossingSubarray(int[] A, int low, int mid, int high) {
        int leftSum = Integer.MIN_VALUE, maxLeft = mid;
        for (int i = mid, sum = 0; i >= low ; --i) {
            sum += A[i];
            if (sum > leftSum) {
                leftSum = sum;
                maxLeft = i;
            }
        }
        int rightSum = Integer.MIN_VALUE, maxRight = mid + 1;
        for (int i = mid + 1, sum = 0; i <= high; ++i) {
            sum += A[i];
            if (sum > rightSum) {
                rightSum = sum;
                maxRight = i;
            }
        }

        return new int[]{maxLeft, maxRight, leftSum + rightSum};
    }

基于动态规划的线性时间方法

　　上述分治策略方法的时间复杂度在\(O(nlgn)\)左右，但实际上最大子数组问题实际上存在一个线性时间\(O(n)\)的方法，并为使用分治方法。
　　我们需要这样理解，如果\(A[1..j]\)已经得到了其最大子数组，那么\(A[1..j+1]\)最大子数组只能是两种情况：

  1. \(A[1..j+1]\)的最大子数组就是\(A[1..j]\)
  2. \(A[1..j+1]\)的最大子数组是\(A[i..j+1],1 \le i \le j\)

　　第一种情况我们很好解决，第二种情况我们该怎么解决呢？
　　我们需要看清一个事实，如果一个子数组它的求和为负的话，它就一定不是最大子数组，所以我们可以用一个\(temp\)保存子数组的求和，一旦为负的话，就将它重置为0。
　　理解了这个思想，代码就很好写了，它实际上也是基于动态规划的，我们用Java实现一下。

Java代码

    /**
     * Find the maximum sub array from the input array A.
     * @param A the input array
     * @return An int array includes the start index of the maximum sub array,
     *         the end index of the maximum sub array and the sum of maximum sub array.
     */
    int[] findMaximumSubarrayDP(int[] A) {
        int len = A.length;
        int maxLeft = 0, maxRight = 0, sumMax = Integer.MIN_VALUE;

        for (int i = 0, temp = 0, cur_left = 0; i < len; ++i) {
            temp += A[i];
            if (temp < 0) {
                temp = 0;
                cur_left = i + 1;
            }
            if (temp > sumMax) {
                sumMax = temp;
                maxLeft = cur_left;
                maxRight = i;
            }
        }

        return new int[]{maxLeft, maxRight, sumMax};
    }
