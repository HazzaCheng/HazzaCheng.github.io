利用线段树和ST算法解决区间最值查询(RMQ)问题

引言

　　关于线段树的介绍，大家看看我之前写的一篇文章线段树小记。

问题定义

　　区间最值问题，即 RMQ(Range Minimum/Maximum Query) 问题，是指对于数组 \(a[0,...,n-1]\)，我们要求高效的查出 \(qs\)(query start) 到 \(qe\)(query end) 之间的最大值或者最小值，其中 \(0 <= qs <= qe <= n-1\)。
　　用暴力的方法，当然很简单，直接遍历一遍，\(O(n)\)的复杂度。
　　还有一种比较耗费空间的做法，利用动态规划，新开一个数组 \(arr[i,j]\)，用来保存 \(i\) 到 \(j\) 之间的最值，这样在预处理之后，可以在 \(O(1)\) 的时间内找到最值，但是需要耗费额外 \(O(n^2)\) 的空间消耗，如果对于特别大的数组，还是会造成挺大的浪费的，接下来我们介绍一下用线段树和ST算法解决这个问题。

线段树

　　关于线段树的，大家可以看看我之前写的那篇文章里，利用线段树解决这个问题，可以在 \(O(log n)\) 的时间效率内进行查询。

　　下面是Java代码：

class SegmentTreeRMQ
{
    int st[]; //array to store segment tree

    /**
     * A utility function to get minimum of two numbers
     * @param x an integer
     * @param y an integer
     * @return the smaller integer
     */
    int minVal(int x, int y) {
        return (x < y) ? x : y;
    }

    /**
     * A utility function to get the middle index from corner indexes
     * @param s the start index
     * @param e the ending index
     * @return the middle index
     */
    int getMid(int s, int e) {
        return (s + e) / 2;
    }

    /**
     * A recursive function to get the minimum value in a given
     * range of array indexes. The following are parameters for
     * this function.
     * @param ss starting indexes of the segment represented by current node, i.e., st[si]
     * @param se ending indexes of the segment represented by current node, i.e., st[si]
     * @param qs starting indexes of query range
     * @param qe ending indexes of query range
     * @param index index of current node in the segment tree
     * @return the minimum value
     */
    int RMQUtil(int ss, int se, int qs, int qe, int index)
    {
        // If segment of this node is a part of given range, then
        // return the min of the segment
        if (qs <= ss && qe >= se)
            return st[index];

        // If segment of this node is outside the given range
        if (se < qs || ss > qe)
            return Integer.MAX_VALUE;

        // If a part of this segment overlaps with the given range
        int mid = getMid(ss, se);
        return minVal(RMQUtil(ss, mid, qs, qe, 2 * index + 1),
                RMQUtil(mid + 1, se, qs, qe, 2 * index + 2));
    }

    /**
     * Return minimum of elements in range from index qs (query start)
     * to qe (query end).  It mainly uses RMQUtil().
     * @param n the length of the input array
     * @param qs starting indexes of query range
     * @param qe ending indexes of query range
     * @return the minimum value
     */
    int RMQ(int n, int qs, int qe)
    {
        // Check for erroneous input values
        if (qs < 0 || qe > n - 1 || qs > qe) {
            System.out.println("Invalid Input");
            return -1;
        }

        return RMQUtil(0, n - 1, qs, qe, 0);
    }

    /**
     * A recursive function that constructs Segment Tree for array[ss..se].
     * si is index of current node in segment tree st.
     * @param arr the input array
     * @param ss starting indexes of the segment represented by current node, i.e., st[si]
     * @param se ending indexes of the segment represented by current node, i.e., st[si]
     * @param si index of current node in the segment tree. Initially 0 is passed as root is always at index 0
     * @return
     */
    int constructSTUtil(int arr[], int ss, int se, int si)
    {
        // If there is one element in array, store it in current node of segment tree and return
        if (ss == se) {
            st[si] = arr[ss];
            return arr[ss];
        }

        // If there are more than one elements, then recur for left and
        // right subtrees and store the minimum of two values in this node
        int mid = getMid(ss, se);
        st[si] = minVal(constructSTUtil(arr, ss, mid, si * 2 + 1),
                constructSTUtil(arr, mid + 1, se, si * 2 + 2));
        return st[si];
    }

    /**
     * Function to construct segment tree from given array. This function
     * allocates memory for segment tree and calls constructSTUtil() to
     * fill the allocated memory
     * @param arr the input array
     */
    void constructST(int arr[])
    {
        int n = arr.length;
        //Height of segment tree
        int x = (int) (Math.ceil(Math.log(n) / Math.log(2)));

        //Maximum size of segment tree
        int max_size = 2 * (int) Math.pow(2, x) - 1;
        st = new int[max_size]; // allocate memory

        // Fill the allocated memory st
        constructSTUtil(arr, 0, n - 1, 0);
    }
    
}

　　这种算法的预处理时间是\(O(n)\)，query时间是\(O(log^n)\)，额外的空间开销是\(O(n)\)。

ST(Sparse Table) 算法

　　ST(Sparse Table) 算法即在线算法，所谓在线算法，是指用户每输入一个查询便马上处理一个查询。该算法一般用较长的时间做预处理，待信息充足以后便可以用较少的时间回答每个查询。ST 算法是一个非常有名的在线处理 RMQ 问题的算法，它可以在 \(O(nlog n)\) 时间内进行预处理，然后在 \(O(1)\) 时间内回答每个查询，还需要 \(O(nlog n)\) 来更新。
　　ST算法也需要用DP进行数据的预处理，设 \(a[0,...,n-1]\) 是要求区间最值的数列，记 lookup 数组为 \(l\)，\(l[i, j]\) 表示从第 \(i\) 个数起连续 \(2^j\) 个数中的最小值。那么如何构造 lookup 数组呢？我们还是用从底向上的算法，我们把 \(l[i，j]\) 平均分成两段（因为 \(2^j\) 一定是偶数个数字），从 \(i\) 到 \(i+2^{j - 1}-1\) 为一段，\(i+2^{j - 1}\) 到 \(i+2^j-1\) 为一段（长度都为\(2^{j-1}\)），于是我们可以得到递归式：

　　

\[l[i,j]=min(l[i,j-1],l[i+2^{j-1},j-1])\]

　　例如 \(a[0,7]\) 的最小值可以分割成 \(a[0,3]\) 和 \(a[4,7]\) 的最小值，整个构造过程如下：

　　还需要注意的是，在更新数组的时候，我们应该是先更新 \(l[i,0]\) 的值，即每个数自身，所以第一层循环需要是列的遍历。
　　预处理完成后，接下来要做的就是查询，假如我们需要查询的区间为 \((i,j)\)，那么我们需要找到覆盖这个闭区间（左边界取 \(i\)，右边界取 \(j\)）的最小幂（可以重复，比如查询 \(1,2,3,4,5\) 我们可以查询 \(1,2,3,4\) 和 \(2,3,4,5\)）。因为这个区间的长度为 \(j-i+1\)，所以我们可以取 \(k=log_2^{j-i+1}\)，则有：

\[l[i,j]=min(l[i,k],l[j-2^k+1,k])\]

　　举例说明，要求区间　\([2,8]\)　的最大值，\(k=log2(8-2+1)=2\)，即求　\(min(l[2, 2]，l[8-2^2+1, 2]) =　min(l[2,2]，l[5,2])\)。
　　下面是Java代码：

public class STRMQ {
    private static int[][] lookup;

    /**
     * Construct the dp array.
     * @param arr the input array
     */
    static void preprocess(int[] arr) {
        int n = arr.length;
        int col = (int) (Math.ceil(Math.log(n) / Math.log(2)));
        lookup = new int[n][col];
        for (int i = 0; i < n; i++) lookup[i][0] = arr[i];
        for (int j = 1; (1 << j) <= n; j++)
            for (int i = 0; i + (1 << j) - 1 < n; i++)
                lookup[i][j] = Math.min(lookup[i][j - 1], lookup[i + (1 << (j - 1))][j - 1]);
    }

    /**
     * Return the minimum value from start to end.
     * @param arr the input array
     * @param start the starting index
     * @param end the ending index
     * @return the minimum number
     */
    int query(int[] arr, int start, int end) {
        int j = (int) (Math.log(end - start + 1) / Math.log(2));
        return Math.min(lookup[start][j],
                lookup[end - (int) Math.pow(2, j)][j]);
    }
}
