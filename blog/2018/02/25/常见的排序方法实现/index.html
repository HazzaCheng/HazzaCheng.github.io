引言

　　复习整理一下排序方法，分别用 java 实现了下，利用 scala 模式匹配的特性又实现了插入排序和归并排序，还有三种线性排序方法，计数排序，基数排序，桶排序这里就不写了。

插入排序

　　很简单，两层循环，每次将第 \(n\) 个值插入前面包含 \(n-1\) 个值的有序序列中。

java 实现

    public static void insertSort(int[] nums) {
        int n = nums.length;
        
        for (int i = 1; i < n; i++) {
            int temp = nums[i], j = i - 1;
            for (; j >= 0; j--) {
                if (nums[j] > temp) nums[j + 1] = nums[j];
                else break;
            }
            nums[j + 1] = temp;
        }
    }

scala 实现

def isort(xs: List[Int]): List[Int] = xs match {
    case List() => List()
    case x :: xs1 => insert(x, isort(xs1))
}

def insert(x: Int, xs: List[Int]): List[Int] = xs match {
    case List() => List(x)
    case y :: ys => if (x <= y) x :: xs else y :: insert(x, ys)
}

希尔排序

　　是插入排序的改进版，主要利用了分组的思想，当数据量比较大的时候，相比于直接插入排序，大大减少了无用的比较，提升了效率。

java 实现

    public static void shellSort(int[] nums) {
        int n = nums.length;
        int gap = n;
        
        do {
            gap = gap / 3 + 1;
            for (int i = gap; i < n; i++) {
                if (nums[i] < nums[i - gap]) {
                    int temp = nums[i], j = i - gap;
                    do {
                        nums[j + gap] = nums[j];
                        j -= gap;
                    } while (j >= 0 && temp < nums[j]);
                    nums[j + gap] = temp;
                }
            }
        } while (gap > 1);
    }

选择排序

　　思路很简单，每次挑选一个极值放入序列前面，效率很低。

java 实现

    public static void selectSort(int[] nums) {
        int n = nums.length;
        
        for (int i = 0; i < n - 1; i++) {
            for (int j = i + 1; j < n; j++) {
                if (nums[i] > nums[j]) swap(nums, i, j);
            }
        }
    }

堆排序

　　堆排序需要利用到最大堆或者最小堆的性质，每次挑选一个极值放在序列的末端，需要实现一个构造堆的函数和维护堆的函数。

java 实现

    private static void maxHeapify(int[] nums, int i, int heapSize) {
        int l = 2 * i + 1;
        int r = 2 * i + 2;
        int max = i;

        if (l < heapSize && nums[l] > nums[max]) max = l;
        if (r < heapSize && nums[r] > nums[max]) max = r;
        if (max != i) {
            swap(nums, max, i);
            maxHeapify(nums, max, heapSize);
        }
    }

    private static void buildMaxHeap(int[] nums, int heapSize) {
        int last = heapSize / 2 - 1;
        for (int i = last; i >= 0; i--) maxHeapify(nums, i, heapSize);
    }

    public static void heapSort(int[] nums) {
        int heapSize = nums.length;
        buildMaxHeap(nums, heapSize);
        while (heapSize > 1) {
            swap(nums, 0, heapSize - 1);
            --heapSize;
            maxHeapify(nums, 0, heapSize);
        }
    }

冒泡排序

　　两层循环，两两比较，将极值移到序列末尾。

java 实现

    public static void bubbleSort(int[] nums) {
        int n = nums.length;
        
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (nums[j] > nums[j + 1]) swap(nums, j, j + 1);
            }
        }
    }

快速排序

　　有点类似与归并排序，但不是按照中间结点分割序列，而是按照某一个值，将小于这个值的移到左边，大于这个值的移到右边。
　　这里我实现的算法中，主元是默认使用第一个元素，如果改成随机抽样，效果可能会更好一点。

java 实现

    public static int quickPartition(int[] nums, int left, int right) {
        int spiltIndex = left;

        for (int i = left + 1; i <= right; i++) {
            if (nums[i] < nums[left]) {
                ++spiltIndex;
                if (spiltIndex != i) swap(nums, spiltIndex, i);
            }
        }
        swap(nums, left, spiltIndex);

        return spiltIndex;
    }

    public static void quickSort(int[] nums, int left, int right) {
        if (left < right) {
            int spiltIndex = quickPartition(nums, left, right);
            quickSort(nums, left, spiltIndex - 1);
            quickSort(nums, spiltIndex + 1, right);
        }
    }

归并排序

　　利用分治思想，将序列不断切割成两部分，然后以牺牲空间的方法，进行排序。

java 实现

    private static void merge(int[] nums, int mid, int left, int right) {
        int[] temp = new int[right - left + 1];
        int l = 0, r = right - left;

        for (int i = left; i <= mid; i++) temp[i - left] = nums[i];
        for (int i = right; i > mid; i--) temp[i - left] = nums[mid + 1 + right - i];
        for (int i = left; i <= right; i++) {
            if (temp[l] < temp[r]) nums[i] = temp[l++];
            else nums[i] = temp[r--];
        }
    }

    public static void mergeSort(int[] nums, int left, int right) {
        if (left >= right) return;
        int mid = (right - left) / 2 + left;
        mergeSort(nums, left, mid);
        mergeSort(nums, mid + 1, right);
        merge(nums, mid, left, right);
    }

scala 实现

def orderedMergeSort[T <: Ordered[T]](xs: List[T]): List[T] = {
    def merge(xs: List[T], ys: List[T]): List[T] =
      (xs, ys) match {
        case (Nil, _) => ys
        case (_, Nil) => xs
        case (x :: xs1, y :: ys1) =>
          if (x < y) x :: merge(xs1, ys)
          else y :: merge(xs, ys1)
      }
    val n = xs.length / 2
    if (n ==0) xs
    else {
      val (zs, ys) = xs splitAt n
      merge(orderedMergeSort(ys), orderedMergeSort(zs))
    }
}

复杂度

　　大体上，内排序有可以分为以下几类：

  1. 插入排序：直接插入排序、二分法插入排序、希尔排序。
  2. 选择排序：直接选择排序、堆排序。
  3. 交换排序：冒泡排序、快速排序。
  4. 归并排序
  5. 基数排序

　　它们的复杂度情况大致如下：
