Bellman-Ford算法

引言

　　Bellman-Ford算法是用来解决一般情况下的单源最短路径问题，并且边的权重可以为负值，但是当其中存在权值为负的环路时，Bellman-Ford算法将将会检测出来，并且不会存在解决方案。

环路问题

　　首先我们先来看一看最短路径中的环路问题。

　　我们可以看到，上图存在两个环路，\(c \leftrightarrow d\)和\(e \leftrightarrow f\)，所不同的是\(c \leftrightarrow d\)是个权值为正的环路，因为\(w(c)+w(d)=3>0\)，所以如果要在找\(s \rightarrow c\)的最短路径，这个路径就是\((s,c)\)，而不会陷入环路之中，因为环路的权值为正。
　　而\(e \leftrightarrow f\)就不同了，因为\(w(e)+w(f)=-3<0\)，所以如果要在找\(s \rightarrow e\)的最短路径，我们无法找出，只会陷入死循环，因为\(e \leftrightarrow f\)的权值小于0，我们会陷入这个环路里。
　　所以一条最短路径不能包含权值为负的环路，而实际上一条最短路径也不能包含权值为正的环路，因为我们只要将环路从路径上删除就能得到一条与原来路径相比权值更小的路径，因为这个环路的权值为正。
　　所以我们可以假定在找到的最短路径里没有环路，即它们都是简单路径。因此\(G=<V,E>\)的任意无环路经，最多包含\(|V|\)个不同的节点和\(|V|-1\)条边。

松弛计算

　　先看第一张图的情况，松弛计算之前，点\(v\)的值是9，但是点\(u\)的值加上边上的权重5，得到7，比点\(v\)的值（9）小，所以，点\(v\)的值减小为7。这个过程的意义是，找到了一条通向\(v\)点更短的路线，且该路线是先经过点\(u\)，然后通过权重为2的边，到达点B。当然，如果出现第二图的情况，则不会修改点\(v\)的值，因为5＋2 > 6。
　　Bellman算法通过对边进行松弛操作来渐进地降低源结点\(s\)到每个结点\(v\)的最短路径的估计值，直到估计值与实际的最短路径权重相同时为止。每次松弛操作实际上是对相邻节点的访问，第\(n\)次松弛操作保证了所有深度为\(n\)的路径最短。由于图的最短路径最长不会经过超过\(V-1\)条边，所以可知Bellman-Ford算法所得为最短路径，我们来看一下它的伪代码：

procedure BellmanFord(list vertices, list edges, vertex source)
   // 该实现读入边和节点的列表，并向两个数组（distance和predecessor）中写入最短路径信息

   // 步骤1：初始化图
   for each vertex v in vertices:
       if v is source then distance[v] := 0
       else distance[v] := infinity
       predecessor[v] := null

   // 步骤2：重复对每一条边进行松弛操作
   for i from 1 to size(vertices)-1:
       for each edge (u, v) with weight w in edges:
           if distance[u] + w < distance[v]:
               distance[v] := distance[u] + w
               predecessor[v] := u

   // 步骤3：检查负权环
   for each edge (u, v) with weight w in edges:
       if distance[u] + w < distance[v]:
           error "图包含了负权环"

　　下图是Bellman-Ford算法的一个示意图，源结点为s，结点中的数值为该结点的d值，加了阴影边表示前驱值。

复杂度

　　Bellman-Ford算法的时间复杂度为\(O(VE)\)，\(V\)是顶点数，\(E\)是边数。

例子

　　基本了解算法以后，我们来一道题目练练手，这是一道非常基本的单源寻找最短路径的应用。

问题描述

　　输入n，m和s，代表n个节点，m条边，s代表源结点，然后是m行输入，每行有x,y,z，代表x到y的路距离为z。问题：求源结点到各个结点的最短路径。
　　这里我们讨论的是有向图的情况，如果是无向图，只要存在一条负边，该图就存在负权回路，这不难理解，无向图的一条边相当于有向图的往返两条边。

Java Codes

　　代码很简单，我们来看一看：

public class Edge implements Comparable<Edge> {
    int x, y;   // two points
    int weight; // the weight of this edge

    public Edge(int x, int y, int weight) {
        this.x = x;
        this.y = y;
        this.weight = weight;
    }

    @Override
    public int compareTo(Edge edge) {
        return this.weight - edge.weight;
    }
}

public class FindShortestPath {
    // dist[i] => the shortest distance form source vertex to vertex i
    private static int[] dist;
    // path[i] => the predecessor vertex of the vertex i
    private static int[] path;
    // the unreachable distance
    private static int INF = Integer.MAX_VALUE - 1000; // prevent integer out of bounds

    /**
     * Util class, cannot be instantiated.
     */
    private FindShortestPath() {}

    /**
     * Initialized the arrays.
     * @param m The number of vertices.
     */
    private static void init(int m) {
        dist = new int[m + 1];
        path = new int[m + 1];

        for (int i = 1; i <= m; i++) {
            dist[i] = INF;
            path[i] = i;
        }
    }

    /**
     * Find the shortest path from source vertex to any vertices and store the paths.
     * @param m The number of vertices.
     * @param source The source vertex.
     * @param edges The edges.
     */
    public static boolean bellmanFord(int m, int source, Edge[] edges) {
        init(m);
        int edgesNum = edges.length;
        dist[source] = 0;

        // relax for m-1 times at most
        for (int i = 0; i < m - 1; i++) {
            boolean flag = false;
            for (int j = 0; j < edgesNum; j++) {
                if (dist[edges[j].x] + edges[j].weight < dist[edges[j].y]) {
                    dist[edges[j].y] = dist[edges[j].x] + edges[j].weight;
                    path[edges[j].y] = edges[j].x;
                    flag = true;
                }
            }
            if (!flag) break;
        }

        // check the negative cycles
        for (int i = 0; i < edgesNum; i++)
            if (dist[edges[i].x] + edges[i].weight < dist[edges[i].y])
                return false;
//                throw new RuntimeException("These edges contain negative cycles!");
        return true;
    }

    /**
     * Get the distance from the source to the v.
     * @param v The vertex.
     * @return The distance.
     */
    public static int getDistanceFromSource(int v) {
        return dist[v];
    }

    /**
     * Print the path from the source to v.
     * @param source The source vertex.
     * @param v The vertex.
     */
    public static void printPath(int source, int v) {
        if (source == v) return;
        Deque<Integer> stack = new ArrayDeque<>();
        int root = v;
        stack.push(root);
        while (root != source) {
            root = path[root];
            stack.push(root);
        }
        stack.pop();
        System.out.print(source);
        while (!stack.isEmpty())
            System.out.print(" --> " + stack.pop());
        System.out.println(" Total distance: " + dist[v]);
    }
}

　　这里有一个优化，我们一个flag，用来在松弛计算时退出循环，如果这一轮的松弛没有使得任何顶点到源点的最短路径变短，那么就不用尝试下一轮松弛了，因为下一轮缩放和这一轮缩放的原理和步骤是一样的，这样就不用非要把\(V-1\)次迭代做完。
　　其实我们还可以做一个优化，这里没有实现，我们每一次松弛的时候如果图中的某条边确实使得源点到其他顶点的最短路径变短，那么下一轮缩放只需要对上一轮松弛的时候使得源点到其他顶点最短路径变短的边的结束点的出边进行松弛就行了，因为下一轮松弛的原理和这一轮是一样的。我们可以用一个队列来储存这些顶点，松弛的时候将这些顶点依次出队，并且将新的符合要求的顶点入队。直到队列为空。
　　这里还需要有个地方注意一下，即INF的值，我们不能设置的过大，要不然在出现负权重环路的情况下，可能会出现溢出的问题。

总结

　　Bellman-Ford需要循环\(n-1\)次来求解最短路，它的每次循环也可以确定一个点的最短路，只不过代价很大，因为Bellman-Ford每次循环都是操作所有边，但是相比于Dijkstra算法，Bellman-Ford 算法的又是就是可以检测负权回路。
