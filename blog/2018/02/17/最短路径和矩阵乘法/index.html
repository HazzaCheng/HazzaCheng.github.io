最短路径和矩阵乘法

引言

　　众所周知，Bellman-Ford算法，SPFA算法，Dijkstra算法都能解决单源最短路径问题。那么我们该如何解决多源最短路径问题呢，即任意两点之间的最短路径。当然我们可以对每个点执行一次单源最短路径算法，这样肯定是可以的，但是我们可以有更好的方法。
　　遇到这种问题，中间量有价值的，我们都会想到DP，因此我们其实可以利用基于DP的算法解决所有结点对的最短路径问题，这篇文章将介绍一下最短路径和矩阵乘法。

算法介绍

　　想要利用DP，我们首先要找出最短路径的结构。根据图论的知识，一条最短路径的所有子路径都是最短路径。
　　我们用邻接矩阵来表示输入图，即\(W=w_{ij}\)，\(p\)为结点\(i\)到\(j\)的一条最短路径，假设点\(i\)和\(j\)不同，将路径\(p\)分解为\(i \rightarrow k \rightarrow j\)，因此\(\sigma(i,j)=\sigma(i.k)+w_{kj}\)。
　　这样，我们便可以构造递归解。我们记\(l_{ij}^{(m)}\)为点\(i\)到\(j\)的至多包含\(m\)条边的任意路径中的最小权重，当\(m=0\)时，不存在一条没有边的最短路径：

\[ f(n) = \begin{cases} 0, & \text{$i = j$} \\ \infty, & \text{$i \neq j$} \end{cases} \]

　　当\(m \ge 1\)时，我们可以由\(l_{ij}^{(m-1)}\)计算\(l_{ij}^{(m)}\)，递归定义：

\[ l_{ij}^{(m)}=\min_{1 \le k \le n}\{l_{ik}^{(m-1)}+w_{kj}\} \]

　　还是比较容易理解的，假设不包含负权值环路，如果\(\sigma(i,j)<\infty\)，从结点\(i\)到\(j\)包含一条最短路径，由于该路径是简单路径，所以其最多包含\(n-1\)条，因此最短路径权重可以如下计算：

\[ \sigma(i,j) = l_{ij}^{(n-1)} = l_{ij}^{(n)} = l_{ij}^{(n+1)} = ... \]

自底向上计算

　　我们可以自底向上计算出最短路径权重，根据输入矩阵\(W=(w_{ij})\)，现在可以计算出矩阵序列\(L^{(1)},L^{(2)},L^{(3)},...,L^{(n-1)}\)，其中\(L^{(m)}=(l_{ij}^{(m)})\)。
　　我们主要是通过如下的方法计算矩阵序列：

\[ L^{(1)}=L^{(0)} \cdot W = W \\ L^{(2)}=L^{(1)} \cdot W = W^2 \\ L^{(3)}=L^{(2)} \cdot W = W^3 \\ ... \\ L^{(n-1)}=L^{(n-2)} \cdot W = W^{n-1} \]

　　\(W\)是权重矩阵，矩阵\(L^{(n-1)}=W^{n-1}\)包含的是最短路径权重，我们用Java实现一下。

Java Codes

    // the unreachable distance
    private static int INF = Integer.MAX_VALUE / 2- 1000; // prevent integer out of bounds
    // adjacency matrix of weight
    private static int[][] matrix;

    /**
     * Initialize the arrays.
     * @param n The number of vertices.
     * @param edges The edges.
     */
    private static void init(int n, Edge[] edges) {
        matrix = new int[n + 1][n + 1];

        // create the adjacency matrix of weight
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) matrix[i][j] = INF;
            matrix[i][i] = 0;
        }
        int len = edges.length;
        for (int i = 0; i < len; i++)
            matrix[edges[i].x][edges[i].y] = edges[i].weight;
    }

    /**
     * Extend one edge to the (m-1) matrix and construct (m) matrix.
     * @param matrix The (m-1) matrix.
     * @param weights The matrix of weights.
     * @return The (m) matrix.
     */
    private static int[][] extendShortestPaths(int[][] matrix, int[][] weights) {
        if (weights == null) return matrix;
        int rowLen = matrix.length, colLen = weights[0].length;
        int midLen = weights.length;
        if (rowLen != colLen && midLen != matrix[0].length)
            throw new RuntimeException("The number of rows and columns must be the same: " +
                "A(" + matrix.length + "," + matrix[0].length + ") B("+ weights.length + "," + weights[0].length + ")");

        int[][] temp = new int[midLen][midLen];
        for (int i = 1; i < midLen; i++) {
            for (int j = 1; j < midLen; j++) {
                temp[i][j] = INF;
                for (int k = 1; k < midLen; k++)
                    temp[i][j] = Math.min(temp[i][j], matrix[i][k] + weights[k][j]);
            }
        }

        return temp;
    }

    /**
     * Find all pairs shortest paths.
     * @param m The number of vertices.
     * @param edges The edges.
     * @return The shortest paths array.
     */
    public static int[][] showAllPairsShortestPaths(int m, Edge[] edges) {
        init(m, edges);
        int[][] weights = matrix;

        for (int i = 2; i < m; i++)
            matrix = extendShortestPaths(matrix, weights);

        return matrix;
    }

　　我们来看一下，主要通过extendShortestPaths这个函数实现了矩阵“乘法”，这里的“乘法”是指找出最短路径，具体可以看实现。还需要注意的是，\(INF\)的值的设置，要考虑到\(INF+INF\)溢出的问题。

复杂度

　　很明显，三层循环再加上需要计算\(m-2\)个矩阵，这种算法的时间复杂度是\(O(n^4)\)。

优化

　　看到上面矩阵的连续运算，如果你接触过快速幂一定会想到些什么，对了，这里我们可以实现矩阵快速幂，也叫重复平方技术，想过知识可以看看这篇文章，浅谈矩阵快速幂。运算过程如下：

\[ L^{(1)}=W = W \\ L^{(2)}= W^2 = W \cdot W \\ L^{(4)}= W^4 = W^2 \cdot W^2 \\ ... \\ L^{(2^{lg (n-1)})}= W^{(2^{lg (n-1)})} = W^{(2^{lg (n-1)-1})} \cdot W^{(2^{lg (n-1)-1})}\\ \]

　　我们来简单的实现一下。

    /**
     * Extend one edge to the (m-1) matrix and construct (m) matrix.
     * @param matrix The (m-1) matrix.
     * @param weights The matrix of weights.
     * @return The (m) matrix.
     */
    private static int[][] extendShortestPaths(int[][] matrix, int[][] weights) {
        if (weights == null) return matrix;
        int rowLen = matrix.length, colLen = weights[0].length;
        int midLen = weights.length;
        if (rowLen != colLen && midLen != matrix[0].length)
            throw new RuntimeException("The number of rows and columns must be the same: " +
                "A(" + matrix.length + "," + matrix[0].length + ") B("+ weights.length + "," + weights[0].length + ")");

        int[][] temp = new int[midLen][midLen];
        for (int i = 1; i < midLen; i++) {
            for (int j = 1; j < midLen; j++) {
                temp[i][j] = INF;
                for (int k = 1; k < midLen; k++)
                    temp[i][j] = Math.min(temp[i][j], matrix[i][k] + weights[k][j]);
            }
        }

        return temp;
    }

    /**
     * Find all pairs shortest paths, using DP and Fast Matrix Exponentiation.
     * @param m The number of vertices.
     * @param edges The edges.
     * @return The shortest paths array.
     */
    public static int[][] showAllPairsShortestPaths_fast(int m, Edge[] edges) {
        init(m, edges);
        int[][] temp = null; // unit matrix

        int i = m - 1;
        while (i != 0) {
            if ((i & 1) == 1) temp = extendShortestPaths(matrix, temp);
            matrix = extendShortestPaths(matrix, matrix);
            i >>= 1;

　　转移矩阵很好找，就是我们的权重矩阵\(W\)，”单位矩阵“需要稍微动下脑筋，我们可以用null代替，在程序里第一次碰到的时候判别一下就可以了。当然，你也可以采取我注释掉的那种方法，不需要“单位矩阵”。

复杂度

　　与没有采取矩阵快速幂的方法需要计算\(m-2\)个矩阵相比，采用矩阵快速幂只需要计算\(lg (n-1)\)个矩阵，所以时间复杂度也下降到\(O(n^3lg n)\)。

总结

　　最短路径和矩阵乘法，基于DP和矩阵快速幂，可以比较高效的计算出随机图里任意两点的最短路径，当然我实现的算法中并没有记录准确的路径，只是记录了最小的开销，大家可以想想如何实现。
