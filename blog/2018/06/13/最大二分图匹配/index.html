引言

　　网络流的一个经典的应用是二分图匹配。常见的二分图匹配问题有两种。第一种是针对无权图的，需要求出包含边数最多的匹配，即二分图的最大基数匹配（maximum cardinality bipartite matching）,第二种是针对带权图的，需要求出边权之和尽量大的匹配。

二分图

　　二分图又称作二部图，是图论中的一种特殊模型。设\(G=(V,E)\)是一个无向图，如果顶点\(V\)可分割为两个互不相交的子集\((U,V)\)，并且图中的每条边\((i,j)\)所关联的两个顶点\(i\)和\(j\)分别属于这两个不同的顶点集(\(i \in U\), \(j \in V\))，则称图\(G\)为一个二分图。

匹配

　　在图论中，一个图是一个匹配（或称独立边集）是指这个图之中，任意两条边都没有公共的顶点。这时每个顶点都至多连出一条边，而每一条边都将一对顶点相匹配。

二分图匹配问题

无权图

　　针对无权图的，需要求出包含边数最多的匹配，即二分图的最大基数匹配（maximum cardinality bipartite matching），如下图所示：

　　这个问题要解决，也不是非常困难，正如上面画的那样，我们可以加一个源点s和一个汇点t，从s到所有X结点各连一条容量为1的弧，再从所有Y结点各连一条容量为1的弧到t，最后把每条边变成一条由X指向Y的有向弧，容量为1。只要求出s到t的最大流，则原图中所有流量为1的弧对应了最大基数匹配。

有权图

　　针对带权图的，需要求出边权之和尽量大的匹配，有些要求这个匹配本身是完美匹配（perfect matching），即每个点都被匹配到，还有的不做限制，我们来考虑下这两种种情况。
　　和最大基数匹配类似，只是原图中所有边的费用为权值的相反数（即前面加一个负号），然后其他边的费用为0，然后求一个s到t的最小费用最大流即可。如果从s出发的所有弧并不是全部满载（即流量等于容量），则说明完美匹配不存在，问题无解；否则原图中的所有流量为1的弧对应最大权完美匹配。用这样的方法也可以求解第二种情况，即匹配边数没有限制的最大权匹配，只是需要在求解s-t最小费用流的过程中记录下流量为0, 1, 2, 3,…时的最小费用流，然后加以比较就可以了。

例子

　　我们举两个题目来看一下二分图，最大二分图和最小权完美匹配的例子，二分图经常会用到拆点法，所以我们再举一个拆点法的例子。

二分图

问题描述

　　对于一个R行C列的正整数矩阵（1≤R，C≤20），设Ai为前i行所有元素之和，Bi为前i列所有元素之和。已知R,C和数组A和B，找一个满足条件的矩阵。矩阵中的元素必须是1～20之间的正整数。输入保证有解。

思路

　　首先根据Ai和Bi计算出第i行的元素之和A‘i和第i列的元素之和B’i。如果把矩阵里的每个数 都减1，则每个A’i会减少C，而每个B’i会减少R。这样一来，每个元素的范围变成了0～19，这么做的原因是因为矩阵中的元素要在1到20之间，而在求最大流的时候是有可能出现0流的，所以这样减去一之后求出的流量（矩阵中的元素）在0到19之间，输出时加一就可以了。立一个二分图，每行对应一个X结点，每列对应一个Y结点，然后增加源点s和汇点t。 对于每个结点Xi，从s到Xi连一条弧，容量为A’i-C；从Yi到t连一条弧，容量为B’i-R。而对于每 对结点(Xi,Yj)，从Xi向Yj连一条弧，容量为19。接下来求s-t的最大流，如果所有s出发和到 达t都满载，说明问题有解，结点Xi->Yj的流量就是格子(i,j)减1之后的值。这其实就是利用到了二分图控制流量的思想。

C++ Codes

　　注意，输出答案不唯一，我的实现只输出一种可能的情况。

#include <iostream>
#include <queue>
#include <cstring>

#define INF 0x5fffffff
#define MAX 105

using namespace std;

static int R, C, s, t;
static int g[MAX][MAX], f[MAX][MAX];

static void init() {
    s = 0, t = R + C + 1;
    int row_sum[MAX];
    int col_sum[MAX];
    memset(g, 0, sizeof(g));
    memset(row_sum, 0, sizeof(row_sum));
    memset(col_sum, 0, sizeof(col_sum));

    for (int i = 1; i <= R; ++i) {
        int tmp = 0;
        cin >> tmp;
        // 计算第i行和
        int sum = tmp - row_sum[i - 1];
        row_sum[i] = tmp;
        g[s][i] = sum - C;

        for (int j = 1; j <= C ; ++j) {
            g[i][R + j] = 19;
        }
    }

    for (int i = 1; i <= C; ++i) {
        int tmp = 0;
        cin >> tmp;
        // 计算第i列和
        int sum = tmp - col_sum[i - 1];
        col_sum[i] = tmp;
        g[R + i][t] = sum - R;
    }
}

static bool solve() {

    int a[t + 1];
    int p[t + 1];
    memset(f, 0, sizeof(f));

    while (true) {
        memset(a, 0, sizeof(a));
        memset(p, 0, sizeof(p));
        queue<int> q;

        a[s] = INF;
        p[s] = s;
        q.push(s);
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (int i = 1; i <= t; ++i) {
                if (!a[i] && g[u][i] > f[u][i]) {
                    a[i] = min(a[u], g[u][i] - f[u][i]);
                    p[i] = u;
                    q.push(i);
                }
            }

            if (a[t]) {
                break;
            }
        }

        if (!a[t]) {
            break;
        }

        for (int u = t; u != s; u = p[u]) {
            f[p[u]][u] += a[t];
            f[u][p[u]] -= a[t];
        }
    }

    // 检查是否满载
    for (int i = 1; i <= R; ++i) {
        if (f[s][i] != g[s][i]) {
            return false;
        }
    }
    for (int i = R + 1; i < t; ++i) {
        if (f[i][t] != g[i][t]) {
            return false;
        }
    }


    return true;
}

static int** make_matrix() {
    int **m = new int*[R];
    for (int i = 0; i < R; ++i) {
        m[i] = new int[C];
    }

    for (int i = 0; i < R; ++i) {
        for (int j = 0; j < C; ++j) {
            m[i][j] = f[i + 1][R + j + 1] + 1;
        }
    }

    return m;
}

int main() {

    while (scanf("%d%d", &R, &C) == 2) {
        if (R == 0 || C == 0) {
            break;
        }

        init();
        cout << endl;
        if (solve()) {
            int **m = make_matrix();

            cout << "Matrix: " << endl;
            for (int i = 0; i < R; ++i) {
                for (int j = 0; j < C; ++j) {
                    cout << m[i][j] << " ";
                }
                cout << endl;
            }

            delete (m);
        } else {
            cout << "无解" << endl;
        }
    }

    return 0;
}

最大二分图匹配

问题描述

　　有n个插座，m个设备和k（n,m,k≤100）种转换器，每种转换器都有无限多。已知每个插 座的类型，每个设备的插头类型，以及每种转换器的插座类型和插头类型。插头和插座类型 都用不超过24个字母表示，插头只能插到类型名称相同的插座中。例如，有4个插座，类型分别为A, B, C, D；有5个设备，插头类型分别为B, C, B, B, X；还有3种转换器，分别是B->X，X->A和X->D。这里用B->X表示插座类型为B，插头类型为X，因此一个插头类型为B的设备插上这种转换器之后就“变成”了一个插头类型为X的设备。转换器可以级联使用，例如插头类型为A的设备依次接上A->B，B->C，C->D这3个转换器之后会“变成”插头类型为D的设备。要求插的设备尽量多。问最少剩几个不匹配的设备。

思路

　　我们可以构造一个网络，首先用Floyd算法算出任意两个插头是否可以转换，然后设设备i对应的插头类型编号为device[i]，插座i对应的插头头类型编号为target[i]，则源点s到所有device[i]连一条弧，容量为1，然后所有target[i]到汇点t连一条弧，容量为1，对于所有设备i和插座j，如果device[i]可以转化为target[j]，则从device[i]连一条弧到target[j]，容量为无穷大（代表允许任意多个设备从device[i]转化为target[j]），最后求s-t最大流，答案就是m减去最大流量。
　　还有一个更加简单的方法：直接把所有插头类型（包括仅在转换器中出现的类型）纳入到网络流模型中，则每个转换器对应一条弧，容量为无穷大。
　　两种方法都有各自优缺点，第一种方法优点是网络流模型中的点比较少（因为只有接线板和设备中出现过的插头类型），缺点是弧比较多（任意一对可以转化的结点之间都有弧），并且编程稍微麻烦一些。第二种方法优点是编程简单，并且弧的个数比较少（只有k条），缺点是点数比较多。建议读者实现这两种算法，然后自 行比较它们的优劣。但是两种方法其实都用到了最大二分图匹配的思想，因为一个插座只能插一个插头，也就是匹配的意思。

C++ Codes

　　我采用第二种思路，你也可以试试第一种思路，需要多写个Floyd算法。

#include <iostream>
#include <vector>
#include <map>
#include <set>
#include <queue>
#include <cstring>

#define INF 0x5fffffff
#define MAX 1005

using namespace std;

static map<string, int> names_map;
static int n, m, k, idx;
static int device[MAX], a[MAX];
static int g[MAX][MAX], f[MAX][MAX];

static void init() {
    idx = 1;
    memset(device, 0, sizeof(device));
    memset(g, 0, sizeof(g));
    memset(f, 0, sizeof(f));

    //　读入插座
    for (int i = 0; i < n; ++i) {
        string str;
        cin >> str;

        if (names_map.count(str) == 0) {
            names_map[str] = idx++;
        }
        g[0][names_map[str]]++;
    }
    //读入设备
    cin >> m;
    for (int i = 0; i < m; ++i) {
        string s1, s2;
        cin >> s1 >> s2;
        if (names_map.count(s2) == 0) {
            names_map[s2] = idx++;
        }
        device[i] = names_map[s2];
    }
    // 读入转换器
    cin >> k;
    for (int i = 0; i < k; ++i) {
        string s1, s2;
        cin >> s1 >> s2;

        if (names_map.count(s1) == 0) {
            names_map[s1] = idx++;
        }
        if (names_map.count(s2) == 0) {
            names_map[s2] = idx++;
        }

        g[names_map[s2]][names_map[s1]] = INF;
    }

    for (int i = 0; i < m; ++i) {
        g[device[i]][idx]++;
    }
}

static int solve() {
    int p[MAX];
    int ans = 0;

    while (true) {
        memset(a, 0, sizeof(a));
        memset(p, 0, sizeof(p));
        a[0] = INF;
        queue<int> q;
        q.push(0);
        while (!q.empty()) {
            int u = q.front();
            q.pop();

            for (int i = 1; i <= idx; ++i) {
                if (!a[i] && g[u][i] > f[u][i]) {
                    a[i] = min(g[u][i] - f[u][i], a[u]);
                    p[i] = u;
                    q.push(i);
                }
            }

            if (a[idx]) {
                break;
            }
        }
        if (!a[idx]) {
            break;
        }
        ans += a[idx];
        for (int u = idx; u != 0; u = p[u]) {
            f[p[u]][u] += a[idx];
            f[u][p[u]] -= a[idx];
        }
    }

    return ans;
}

int main() {

    while (scanf("%d", &n) == 1) {
        if (n == 0) {
            break;
        }

        init();

        int ans = m - solve();

        cout << ans << " " << endl;
    }

    return 0;
}

拆点法

问题描述

　　给出一个v（3≤v≤1000）个点e（3≤e≤10000）条边的有向加权图，求1～v的两条不相交（除了起点和终点外没有公共点）的路径，使得权和最小。

思路

　　把2到v-1的每个结点i拆成i和i’两个结点，中间连一条容量为1，费用为0的边，然后求1到v的流量为2的最小费用流即可。拆点法是解决结点容量的通用方法。

C++ Codes

#include <iostream>
#include <queue>
#include <vector>
#include <cstring>

using namespace std;

static const int INF = 0x4ffffff;
static const int MAX = 100005;

struct Edge {
    int from, to, cap, flow, cost;
    Edge(int u, int v, int c, int f, int w): from(u), to(v), cap(c), flow(f), cost(w) {}
};

static int n, m;
static vector<Edge> edges;
static vector<int> g[MAX];
static int in_queue[MAX], a[MAX], p[MAX], d[MAX];


static void addEdges(int u, int v, int cap, int cost) {
    edges.push_back(Edge(u, v, cap, 0, cost));
    g[u].push_back(edges.size() - 1);
    edges.push_back(Edge(v, u, 0, 0, -cost));
    g[v].push_back(edges.size() - 1);
}

static void init() {
    edges.clear();
    for (int i = 0; i <= n; ++i) {
        g[i].clear();
    }

    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        addEdges((u * 2) ^ 1, v * 2, 1, w);
    }

    for (int i = 2; i < n; ++i) {
        addEdges(i * 2, (i * 2) ^ 1, 1, 0);
    }
    addEdges(2, 3, 2, 0);
    addEdges(n * 2, (n * 2) ^ 1, 2, 0);
}

static bool bellman_ford(int s, int t, int& flow, int& cost) {
    queue<int> q;

    for (int i = 0; i <= MAX; ++i) {
        d[i] = INF;
        p[i] = i;
        in_queue[i] = 0;
        a[i] = 0;
    }

    a[s] = INF;
    d[s] = 0;
    p[s] = s;
    in_queue[s] = 1;

    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        in_queue[u] = 0;
        for (int i = 0; i < g[u].size(); ++i) {
            Edge &e = edges[g[u][i]];
            if (e.cap > e.flow && d[e.to] > d[u] + e.cost) {
                d[e.to] = d[u] + e.cost;
                a[e.to] = min(a[u], e.cap - e.flow);
                p[e.to] = g[u][i];
                if (!in_queue[e.to]) {
                    q.push(e.to);
                    in_queue[e.to] = 1;
                }
            }
        }
    }
    
    if (d[t] == INF) {
        return false;
    }
    for (int u = t; u != s; u = edges[p[u]].from) {
        edges[p[u]].flow += a[t];
        edges[p[u] ^ 1].flow -= a[t];
    }
    cost += a[t] * d[t];
    flow += a[t];


    return true;
}

static int mcmf(int s, int t, int &cost) {
    int flow = 0;

    while (bellman_ford(s, t, flow, cost)) {
    }

    return flow;
}

int main() {

    while (scanf("%d %d", &n, &m) == 2) {
        if (n == 0 || m == 0) {
            break;
        }

        init();

        int cost = 0;
        mcmf(2, (n * 2) ^ 1, cost);

        printf("%d\n", cost);
    }

    return 0;
}

最小权完美匹配

问题描述

　　给n个点（n≤100）的有向带权图，找若干个有向圈，每个点恰好属于一个圈。要求权和 尽量小。注意即使(u,v)和(v,u)都存在，它们的权值也不一定相同。

思路

　　每个点恰好属于一个有向圈，意味着每个点都有一个唯一的后继。反过来，只要每个点都有唯一的后继，每个点一定恰好属于一个圈。“每个东西恰好有唯一的……”让我们想到了 二分图匹配。把每个点i拆成Xi和Yi，原图中的有向边u->v对应二分图中的边Xu->Yv，则题目转化为了这个二分图上的最小权完美匹配问题。

C++ Codes

#include <iostream>
#include <vector>
#include <queue>
#include <cstring>

using namespace std;

const static int INF = 0x6fffffff;
const static int MAX = 1005;

struct Edge {
    int from, to, cap, flow, cost;
    Edge(int u, int v, int c, int f, int w): from(u), to(v), cap(c), flow(f), cost(w) {}
};

static int n, s, t;
static vector<Edge> edges;
static vector<int> g[MAX];
static int a[MAX], p[MAX], d[MAX], in_queue[MAX];

static void addEdges(int u, int v, int cap, int cost) {
    edges.push_back(Edge(u, v, cap, 0, cost));
    g[u].push_back(edges.size() - 1);
    edges.push_back(Edge(v, u, 0, 0, -cost));
    g[v].push_back(edges.size() - 1);
}

static void init() {
    edges.clear();
    for (int i = 0; i <= n; ++i) {
        g[i].clear();
    }

    s = 0;
    t = n * 2 + 1;

    for (int i = 1; i <= n; ++i) {
        addEdges(s, i, 1, 0);
        addEdges(n + i, t, 1, 0);
    }

    for (int i = 1; i <= n; ++i) {
        int v, d;
        while (scanf("%d", &v) == 1 && v != 0) {
            cin >> d;
            addEdges(i, n + v, 1, d);
        }
    }
}

static bool bellman_ford(int& flow, int& cost) {
    queue<int> q;

    for (int i = 0; i <= MAX; ++i) {
        d[i] = INF;
        p[i] = i;
        in_queue[i] = 0;
        a[i] = 0;
    }

    a[s] = INF;
    d[s] = 0;
    p[s] = s;
    in_queue[s] = 1;

    q.push(s);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        in_queue[u] = 0;
        for (int i = 0; i < g[u].size(); ++i) {
            Edge &e = edges[g[u][i]];
            if (e.cap > e.flow && d[e.to] > d[u] + e.cost) {
                d[e.to] = d[u] + e.cost;
