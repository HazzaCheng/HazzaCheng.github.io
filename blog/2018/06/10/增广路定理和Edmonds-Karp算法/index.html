引言

　　本文简单的记录了最大流问题增广路定理，并且利用增广路定理解决了最大流问题，具体实现了Edmonds-Karp算法，最后还粗略的介绍了一下最大流最小割定理。

最大流

　　要说增广路定理，我们首先要看一看流网络和最大流。

流网络

　　流网络\(G=(V,E)\)是一个有向图，图中每条边\((u,v)\in E\)有一个非负的容量值\(c(u,v) \ge 0\)而且，如果边集合\(E\)包含一条边\((u,v)\)，则图中不存在反方向的边\((v,u)\)。如果\((u,v) \notin E\)，则为方便起见，定义\(c(u,v) = 0\)，并且在图中不允许自循环。在流网络的所有结点中，我们特别分辨出两个特殊结点：源结点\(s\)和汇点\(t\)。为方便起见，假定每个结点都在从源结点到汇点的某条路径上。也就是说，对于每个结点\(v \in V\)，流网络都包 含一条路径\(s \to \ v \to p\)。因此，流网络图是连通的，并且由于除源结点外的每个结点都至少有一条进人的边，我们有\(|E| \ge |V| - 1\)。下图描述的是一个流网络的例子。

　　我们现在可以给出流的形式化定义。设\(G=(U,V)\)为一个流网络，其容量函数为\(c\)，\(s\)为网络的源结点，\(t\)为汇点。\(G\)中的流是一个实值函数\(f:V \times V \to R\)，满足下面的两条性质：

  • 流量限制：对于所有结点\(u,v \in E\)，要求\(0 \le f(u,v) \le c(u,v)\)。
  • 流量守恒：对于所有结点\(u \in V - \{s, t\}\)，要求\(\sum_{v \in V}f(u,v) = \sum_{v \in V}f(v,u)\)。

　　当\((u,v) \notin E\)时，从结点\(u\)到结点\(v\)之间没有流，因此\(f(u, v) = 0\)。
　　我们称非负数值\(f(u,v)\)为从结点\(u\)到结点\(v\)流。一个流\(f\)的值\(|f|\)定义如下：

\[ |f| = \sum_{v \in V}f(s,v) - \sum_{v \in V}f(v,s)\]

　　也就是说，流\(f\)的值是从源结点流出的总流量减去流人源结点的总流量。
　　我们简略地对流的定义和流的两种性质进行探讨。容量限制性质说明，从一个结点到另一个结点之间的流必须为非负值且不能超过给定的容量限额。流量守恒性质说明，流人一个结点（指非源结点和非汇点）的总流量必须等于流出该结点的总流量，非形式化地称为“流人等于流出”。

最大流

　　在最大流问题中，给定一个流网络，一个源结点，一个汇点，我们希望找到值最大的一个流。

残存网络

　　残存网络比较容易理解，就是\(f\)和\(c\)的一个差值，我们下面这个图就可以理解：

　　你可能有些疑问，流网络中，如果\((u,v)\in E\)，则\((v,u)\notin E\)，那为什么图中都画出来了，这只是一种表示方法。残存网络还可能包含图中不存在的边。算法对流量进行操作的目标是增加总流量，为此，算法可能对某些特定边上的流量进行缩减。为了表示对一个正流量\(f(u, v)\)的缩减，我们将边\((v,u)\)也加人到图中，并将其残存容量设置为\(c_f(v, u) - f(u, v)\)。也就是说，一条边所能允许的反向流量最多将其正向流量抵消。残存网络中的这些反向边允许算法将已经发送出来的流量发送回去。而将流量从同一条边发送回去等同于缩减该条边的流量，这种操作在许多算法中都是必需的。更形式化地，假定有一个流网络\(G=(V, E)\)，其源结点为\(s\)汇点为\(t\)。设\(f\)为图\(G\)中的一个流，考虑结点对\((u, v) \in E\)，定义残存容量\(c_f(u, v)\)如下：

\[ c_f(u,v) = \begin{cases} c(u,v) - f(u,v) & \text{if $(u,v) \in E$} \\ f(u,v) & \text{if $(v,u) \in E$} \\ 0, & \text{else} \\ \end{cases} \]

增广路算法

增广路径

　　理解了残存网络的概念，增广路径（augmenting path）就比较容易理解了，给定流网络\(G=(V, E)\)和流\(f\)，增广路径\(p\)是残存网络中一条从源结点\(s\)到汇点\(t\)的简单路径。根据残存网络的定义，对于一条增广路径上的边\((u,v)\)，我们可以增加其流量的幅度最大为\(c_f(u, v)\)，而不会违反原始流网络中对边\((u,v)\)或\((v,u)\)的容量限制。

增广路定理

　　那么所谓的增广路算法就是求出路径中所有残量的最小值\(d\)，然后把对应的所有边上的流量加上\(d\)即可，也就是增广（augumenting）的过程。
　　只要残量网络存在增广路径，流量就可以增大，这也是所谓的增广路定理。

Edmonds-Karp

　　增广路算法基本的算法是Ford-Fulkerson算法，它基本的伪代码也很容易理解：

　　但是，你也很容易发现，问题的关键在于算法的第三行是如何搜索简单路径的，关于搜索任意路径，你肯定会想到DFS和BFS，DFS无疑是最好的，但是也经常会碰到很慢的情况，所以我们使用BFS的方法，也就是Edmonds-Karp算法，它的时间复杂度是\(O(VE^2)\)。
　　我们用Java实现一下。

Java Code

public class FlowEdge {
    public int from, to;
    public int flow, cap;

    public FlowEdge() {
        from = 0;
        to = 0;
        flow = 0;
        cap = 0;
    }

    public FlowEdge(int from, int to, int flow, int cap) {
        this.from = from;
        this.to = to;
        this.flow = flow;
        this.cap = cap;
    }
}

public class MaximumFlow {
    private static final int INF = Integer.MAX_VALUE - 100000;

    /**
     * The edges in the flow networks.
     */
    private static FlowEdge[] edges;
    /**
     * The flow networks.
     */
    private static Map<Integer, List<Integer>> graph;


    /**
     *  Util class, cannot be instantiated.
     */
    private MaximumFlow() {}

    /**
     * The initialization.
     * @param n The number of vertices.
     * @param m The number of edges.
     * @param edgesArr The input edges.
     */
    private static void init(int n, int m, int[][] edgesArr) {
        edges = new FlowEdge[m * 2];
        graph = new HashMap<>(n);

        addEdges(edgesArr);
    }

    /**
     * Add edges to the graph.
     * @param edgesArr The input edges.
     */
    private static void addEdges(int[][] edgesArr) {
        int i = 0;
        for (int[] edge: edgesArr) {
            edges[i++] = new FlowEdge(edge[0], edge[1], 0, edge[2]);
            // The antiparallel edge.
            edges[i++] = new FlowEdge(edge[1], edge[0], 0, 0);
            List<Integer> temp;
            temp = graph.getOrDefault(edge[0], new ArrayList<>());
            temp.add(i - 2);
            graph.put(edge[0], temp);
            temp = graph.getOrDefault(edge[1], new ArrayList<>());
            temp.add(i - 1);
            graph.put(edge[1], temp);
        }
    }

    /**
     * Use Edmonds-Karp Algorithm to find the maximum flow.
     * @param n The number of vertices.
     * @param m The number of edges.
     * @param edgesArr The input edges.
     * @param start The source node.
     * @param end The sink node.
     * @return
     */
    public static int edmondsKarp(int n, int m, int[][] edgesArr, int start, int end) {
        init(n, m, edgesArr);

        int ans = 0;

        while (true) {
            Queue<Integer> queue = new LinkedList<>();
            // the increment from the start
            int[] a = new int[n];
            // the paths.
            int[] p = new int[n];

            queue.offer(start);
            a[start] = INF;
            while (!queue.isEmpty()) {
                int x = queue.poll();
                List<Integer> connected = graph.getOrDefault(x, new ArrayList<>());
                int len = connected.size();
                for (int i = 0; i < len; i++) {
                    FlowEdge e = edges[connected.get(i)];
                    if (a[e.to] == 0 && e.flow < e.cap) {
                        p[e.to] = connected.get(i);
                        a[e.to] = Math.min(a[x], e.cap - e.flow);
                        queue.offer(e.to);
                    }
                }

                if (a[end] != 0) {
                    break;
                }
            }
            // find all augmenting paths
            if (a[end] == 0) {
                break;
            }
            // add the flow
            for (int u = end; u != start; u = edges[p[u]].from) {
                edges[p[u]].flow += a[end];
                edges[p[u] ^ 1].flow -= a[end];
            }
            ans += a[end];
        }

        return ans;
    }

}

　　还是比较容易理解的，我们用了一个小技巧，就是把一个边和它的反向边保存在一起，连续的保存，也就是0号边和1号边互为反向，而2号边和3号边互为反向，然后通过一个二进制技巧p[u] ^ 1快速找到它的反向边，也就是一个差值为1的奇偶数互换。

C++ Codes

　　我们再用C++实现一下。


#include <iostream>
#include <vector>
#include <queue>
#include <cstring>

#define MAX 100000
#define INF 0x6fffffff


using namespace std;

struct FlowEdge {
    int from, to, cap, flow;

    FlowEdge(int f, int t, int c, int fl): from(f), to(t), cap(c), flow(fl) {}
};

static int n, m;
static vector<FlowEdge> edges;
static vector<int> g[MAX];
static int a[MAX], p[MAX];

static void init() {
    edges.clear();
    for (int i = 0; i < n; ++i) {
        g[i].clear();
    }
}

static void add_edge(int from, int to, int cap) {
    edges.push_back(FlowEdge(from, to, cap, 0));
    g[from].push_back(edges.size() - 1);
    edges.push_back(FlowEdge(to, from, 0, 0));
    g[to].push_back(edges.size() - 1);
}

static int edmonds_karp(int s, int t) {

    int flow = 0;

    while (true) {
        memset(a, 0, sizeof(a));
        memset(p, 0, sizeof(p));
        queue<int> q;

        q.push(s);
        a[s] = INF;
        while (!q.empty()) {
            int u = q.front();
            q.pop();

            for (int i = 0; i < g[u].size(); ++i) {
                FlowEdge &e = edges[g[u][i]];
                if (!a[e.to] && e.cap > e.flow) {
                    a[e.to] = min(a[u], e.cap - e.flow);
                    p[e.to] = g[u][i];
                    q.push(e.to);
                }
            }
            if (a[t]) {
                break;
            }
        }

        if (!a[t]) {
            break;
        }

        for (int i = t; i != s ; i = edges[p[i]].from) {
            edges[p[i]].flow += a[t];
            edges[p[i] ^ 1].flow -= a[t];
        }

        flow += a[t];
    }

    return flow;
}

int main() {

    while (scanf("%d%d", &n, &m) == 2) {
        if (n == 0 || m == 0) {
            break;
        }

        init();

        for (int i = 0; i < m; ++i) {
            int f, t, c;
            cin >> f >> t >> c;
            add_edge(f, t, c);
        }

        int flow = edmonds_karp(0, n - 1);
        cout << flow << endl;
    }

    return 0;
}

最大流最小割定理

　　我们先看一看什么是最小割。

最小割

　　一个\(s-t\)割\(C = (S, T)\)是一种\(V\)的划分使得\(s \in S, t \in T\)，\(C\)的割集是集合：

\[ \{(u,v) \in E \ : \ u \in S, v \in T\} \]

　　因此如果 C 的割集是空集合，则\(|f| = 0\)。一个\(s-t\)割的容量是:

\[ c(S,T)=\sum \nolimits _{(u,v) \in (S \times T) \cap E}c_{uv}=\sum \nolimits _{(i,j) \in E}c_{ij}d_{ij} \]

　　其中\(d_{ij}=1\)，如果\(i\in S\)并且\(j\in T\)，反之。
　　最小\(s-t\)割问题就是计算\(c(S, T)\)的最小值。即找到\(S\)和\(T\)使\(s-t\)割的容量达到它的最小值。

定理

　　最大流最小割定理提供了对于一个网络流，从源点到目标点的最大的流量等于最小割的每一条边的和。即对于一个如果移除其中任何一边就会断开源点和目标点的边的集合的边的容量的总和。证明这里就不赘述了，有兴趣可以自己google一下。

总结

　　解决最大流问题，我们可以通过不断地进行增广操作，直至找不到增广路经也就找到了最大流，在搜索简单路径时我们可以采用BFS的方法，并且最后我们简单的介绍了一下最大流最小割定理。
