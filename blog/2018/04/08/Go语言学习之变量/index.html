引言

　　本文将作一些Go语言中涉及变量的一些笔记，这里只记录Go语言和其它语言不太一样的地方。

删除未使用的导入

　　Go语言中必须删除未使用的导入，否则编译器会将其当作错误。

变量声明

　　使用var声明变量，支持类型推断，例如var x int32或var s = "hello, world!"，在函数内部，还可以省略var关键字，使用更简单的定义模式，例如x := 10。
　　注意，编译器将未使用的局部变量定义也当作成错误。

切片实现类似动态数组

　　切片（slice）可实现类似动态数组的功能：

x := make([]int, 0, 5) // 初始容量为5的切片

for i := 0; i < 8; i++ {
	x = append(x, i)
}

字典操作以及ok-idiom模式

　　Go中将字典(map)类型内置，可直接从运行时层面获得性能优化。

m := make(map[string]int)	// 创建
m["a"] = 1					// 添加或赋值
x, ok := m["b"]				// 使用ok-idiom可知道key/value是否存在
delete(m, "a")			 // 删除

所谓ok-idiom模式，是指在多返回值中用一个名为ok的布尔值来表示操作是否成功。

结构体可匿名嵌入其他类型

　　结构体（struct）可匿名嵌入其他类型，并且直接访问匿名字段的成员。

type user struct {
	name string
	age byte
}

type manager struct {
	user			// 匿名嵌入其他类型
	title string
}

func main() {
	var m manager
	
	m.age = 22 // 直接访问匿名字段的成员
	m.name = "Hazza"
	m.title = "CTO"
	
	fmt.Println(m)
}

接口采用duck type

　　接口采用了duck type方式，也就是说无须在实现类型上添加显式声明。

type user struct {
	name string
	age int
}

func (u user) Print() {
	fmt.Printf("%+v\n", u)
}

type Printer interface {
	Print()
} 

func main() {
	var u user
	u.name = "Tom"
	u.age = 29
	
	var p Printer = u
	p.Print()
}

静态类型语言

　　Go是静态类型语言，变量总是有着固定的数据类型，类型决定了变量内存的长度存储格式，我们只能修改变量的值，不能修改变量的类型。

不同类型初始化值

　　关键字var用于定义变量，可以一次定义多个变量，包括用不同初始值定义不同类型。

var a, s = 100, "abc"

　　依照惯例，建议以组的方式整理多行变量定义

var (
	x, y int
	a, s = 100, "abc"
)

简短模式

　　我们也可以不使用var，用:=来变量定义和初始化，它有一些限制：

  • 定义变量，同时显式初始化
  • 不能提供数据类型
  • 只能用在函数内部

退化赋值

　　退话化赋值的条件是最少有一个新变量被定义，且必须是同一作用域。

x := 100
x, y := 200, "abc"  // x退化为赋值操作，仅有y是变量定义

多变量赋值

　　在进行多变量赋值操作时，首先先计算出所有右值，然后再依次完成赋值操作，例如x, y = y+3, x+2，先计算出y+3和x+2后，再对x和y变量赋值。

空标识符

　　Go有一个名为"_“的特殊成员（blank identifier），通常作为忽略占位符使用，可作表达式左值，无法读取内容。

func main() {
	x, _ := strconv.Atoi("12") 	// 忽略Atoi的err返回值
	println(x)
}

常量

　　与变量不同，未曾使用的常量不会引发编译错误，常量值必须是编译期可确定的字符，字符串，数字或布尔值。

func main() {
	const (
		a, b = 123, "hello"
		c = false
	) 
	
	const x = 1.22
	
	{
		const x = "aaa"	// 在不同作用域定义同名常量
	}
}

　　常量也可以是某些编译器能计算出来结果的表达式。

func main() {
	const (
		ptrSize = unsafe.Sizeof(uintptr(0))
		strSize = len("hello")
	)
}

　　在常量组中，如不指定类型和初始化值，则与上一行非空常量右值（表达式文本）相同。

func main() {
	
	const (
		x uint16 = 120
		y	// 与上一行x类型，右值相同
		s = "abc"
		z	// 与上一行x类型，右值相同
	)

}

枚举

　　Go没有明确意义上的enum定义，但是可借助iota标识符实现一组自增量常值来实现枚举类型。

	const (
		x = iota	// 0
		y			// 1
		z			//2
	) 
	
	const (
		_ = iota
		KB = 1 << (10 * iota)	// 1 << (10 * 1)
		MB						// 1 << (10 * 2)
		GB 						// 1 << (10 * 3)
	)

　　自增作用范围是常量组，可在多个常量定义中使用多个iota，它们各自单独计数，只须确保组中每行常量的列数量相同即可。

	const (
		_, _ = iota, iota * 10
		a, b
		c, d
	)

　　如中断iota子增，必须ｉ显示恢复，且后续自增值按行序递增。

	const (
		a = iota	// 0
		b			// 1
		c = 100		// 100
		d			// 100
		e = iota	// 4(恢复iota自增，计数包括c,d)
		f			// 5
	)

　　i的子增自增默认为数据类型为int，也可显示指定类型。

    const (
		a = iota			// int
		b float32 = iota	// float32
		c 					// float32
	)

　　在实际编码中，建议使用自定义类型实现用途明确的枚举类型，但这并不能将取值范围限定在预定义的枚举值中。

type color byte

const (
	black color = iota
	red
	blue
)

func test(c color)  {
	println(c)
}

func main() {
	test(red)
	test(100)
}

output:
1
100

　　我们可以看到我们输入100也是可以输出的，但是你不能显示的输出入int类型的。

引用类型分配内存

　　所谓引用类型（reference type）特指slice，map，channel这三种预定义类型。引用类型我们可以使用make函数创建，编译器会将make转换为目标类型专用的创建函数（或指令），以确保完成全部内存分配和相关属性初始化，例如：

	s := make([]int, 0, 10)
	s = append(s, 100)
	
	m := make(map[string]int)
	m["a"] = 1

　　new函数也可以为引用类型分配内存，但是是不完整创建，例如说字典类型，它仅分配了字典类型本身（实际就是个指针包装）所需内存，并没有分配键值存储内存，也没有初始化散列桶等内部属性，因此它无法正常工作：

func main() {
	p := new(map[string]int)
	m := *p
	m["a"] = 1
	fmt.Print(m)
}

output:
panic: assignment to entry in nil map

按位清除

　　Go里面有一个比较特殊的位运算符，按位清除&^，它将左右操作数对应的二进制位都为1的重置为0，以达到一次清除多个标记位的目的，例如1011 & 1101 = 0010。

自增和自减

　　自增和自减不再当作是运算符，只能作为独立语句，不能用于表达式，例如if (a++) > 1是不合法的，并且没有前置的自增和自减，只有后置的。

指针

　　内存地址和指针是不一样的：

  • 内存地址是内存中每个字节单元的唯一编号，而指针则是一个实体。
  • 指针则是一个实体，指针会分配内存空间，相当于一个专门用来保存地址的整型变量。

　　取址运算符&用来获取对象地址，指针运算符*用于间接引用目标对象。
　　不是所有对象都能进行取址操作，但变量总是能返回地址（addressable），和C++一样，指针运算符为左值时我们可以更新目标对象状态，而右值时则是为了获取目标状态。

func main() {
	x := 10

	var p *int = &x
	q := &x

	println(*p, p, q, p == q)
}

　　与C++不同，指针没有专门指向成员的->运算符，统一使用.选择表达式：

func main() {
	a := struct {
		x int
	}{}

	a.x = 100

	p := &a
	p.x += 100

	println(p.x)
}

初始化

　　对所谓的复合类型（数组，切片，字典，结构体）变量初始化的时候，有一些语法限制：

  • 初始化表达式必须包含类型标签
  • 坐花括号必须在类型尾部，不能另起一行
  • 多个成员初始值以逗号分隔
  • 允许多行，但每行必须以逗号或右花括号结束

　　正确示例：

type data struct {
	x int
	s string
}

var a data = data{1, "abc"}

b := data{
	1,
	"abc",
}

c := []int{
	1,
	2}
	
	d := []int{1, 2
	3, 4,
	5
}

　　错误示例：


type data struct {
	x int
	s string
}

var d data = {1, "abc"}		// 缺类型标签

d := data
	{	// 左花括号不能另起一行
		1, 
		"abc"
	}
	
d := data{
	1,
	"abc"	// 必须以逗号或花括号结束
}
