引言

　　本文将作一些Go语言中涉及表达式的一些笔记，这里只记录Go语言和其它语言不太一样的地方。

没有while循环

　　Go中没有while循环流控制语句，while的功能可以由for循环代替，例如while x < 5可由for x < 5代替。

for…range返回索引

　　在迭代遍历时，for...range除元素外还可以返回索引，对于字典则还会返回key，例如：

x := []int{1, 2, 3}

for i, n := range x {
println(i, ":", x)
}

m := make(map[string]int, 10)

for i := 0; i < 10; i++ {
	m[strconv.Itoa(i)] = i
}

for k, v := range m {
	println(k, v)
}

　　可改用数组指针或切片类型。

defer定义延迟调用

　　用defer定义延迟调用，无论函数出错与否，它都确保结束前被调用。常用来释放资源，解除锁定，执行一些清理操作。可定义多个defer，按FIFO顺序执行。

func test(a, b int) {
	defer println("hello...")
	
	println(a / b)
}

if支持初始化语句

　　if语句不仅支持逻辑判断，还支持初始化语句。

func main() {
	x := 100
	y := 20
	
	if a, b := x + 10, y + 10; a < b {
		
	}	
}

func check(x int) error {
	if x < 0 {
		return errors.New("x <= 0")
	}
	
	return nil
}

func main() {
	x := 100

	if err := check(x); err == nil {
		x++
		println(x)
	}
}

switch支持初始化

　　和if语句一样，switch语句也支持初始化语句。

func main() {
	
	switch x := 5; x {
	default:
		x += 100
		println(x)
	case 5:
		x += 50
		println(x)
	}
		
}

　　并且我们看到即使我们把default写在了最上面，但是只有执行所有case语句失败后才会执行default语句。
　　与其他语言的不同，case执行完毕后自动中断，无须显示的执行break语句，如需贯通后面的case语句（完全按照源码顺序），需要在最后加上fallthrough关键词，但不再匹配后面的条件表达式。

func main() {

	switch x := 5; x {
	default:
		x += 100
		println(x)
	case 5:
		x += 50
		println(x)

		fallthrough	// 继续执行下一case，但不再匹配条件表达式
	case 6:
		x += 20
		println(x)
	case 7:
		x += 10
		println(x)

		//fallthrough	// 如加上不会再执行default，完全按照源码顺序，只会报错
	}

}

　　fallthrough必须放在case块结尾，可使用break语阻止。

func main() {

	switch x := 5; x {
	default:
		x += 100
		println(x)
	case 5:
		x += 50
		println(x)

		if x < 100 {
			break	// 终止，不再执行后续语句，即使有fallthrough语句
		}
		
		fallthrough	
	case 6:
		x += 20
		println(x)
	
	}

}
