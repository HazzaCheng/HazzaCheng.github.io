引言

　　本文将作一些Go语言中涉及数据的一些笔记，这里只记录Go语言和其它语言不太一样的地方。

字符串

　　Go里的字符串也是不可变的，是不可变字节（byte）序列，其本身也是一个复合结构，我们可以看一下它大致的结构：

type stringStruct struct {
	string unsafe.Pointer
	len int
}

　　头部指针指向字节数组，内置函数len返回字节数组长度。 　　同样，我们可以使用"`“定义不做转义的原始字符串（raw string），支持跨行，并且缩进也是存在的：

func main() {
	s := `line1\r\n,
		line 2`

	println(s)
}

输出：
line1\r\n,
		line 2

　　支持”~=，==，<，>，+，+=“操作符，比较是按照字典序的。 　　可以通过像数组那样的索引访问字节元素，但是不能获得元素的地址：

func main() {
	s := "abc"

	println(s[1])
	println(&s[1])	// cannot take the address of the s[1]
}

　　以切片语法（起始和结束索引号）返回字串，其内部依旧指向原字节数组。
　　使用for遍历字符串，分byte和rune两种方式，分别打印byte和字符：

func main() {
	s := "中国"

	// byte
	for i := 0; i < len(s); i++ {
		fmt.Printf("%d: [%c]\n", i, s[i])
	}
	fmt.Println()
	// rune: 返回数组索引号，以及Unicode字符
	for i, c := range s {
		fmt.Printf("%d: [%c]\n", i, c)
	}
}

转换

　　要修改字符串，须将其转换为可变类型，[]rune或[]byte，待完成后再转换回来，但是不管如何转换，都必须重新分配内存，并复制数据。

func pp(format string, ptr interface{}) {
	p := reflect.ValueOf(ptr).Pointer()
	h := (*uintptr) (unsafe.Pointer(p))
	fmt.Printf(format, *h)
}

func main() {
	s := "hello, world!"
	pp("s: %x\n", &s)

	bs := []byte(s)
	s2 := string(bs)

	pp("string to []byte, bs: %x\n", &bs)
	pp("[]byte to string, s2: %x\n", &s2)

	rs := []rune(s)
	s3 := string(rs)

	pp("string to []rune, rs: %x\n", &rs)
	pp("[]rune to string, s3: %x\n", &s3)
}

　　转换操作有时会拖累算法性能，我们可以尝试用“非安全”方法进行改善。

func pp(format string, ptr interface{}) {
	p := reflect.ValueOf(ptr).Pointer()
	h := (*uintptr) (unsafe.Pointer(p))
	fmt.Printf(format, *h)
}

func main() {
	bs := []byte("Hello, world!")
	s := toString(bs)

	pp("bs: %x\n", &bs)
	pp("s: %x\n", &s)
}

　　这个方法利用[]byte和string头结构“部分相同”，以非安全的指针类型转换来实现类型“变更”，从而避免了底层数组复制，可以有效的改善执行性能，但是使用unsafe是由风险的。
　　使用append函数也可以将string直接追加到[]byte内。

性能

　　创造动态字符串时也容易造成性能问题，和Java一样，用加法操作符拼接字符串时，每次都必须分配内存，构建新的对象。但是我们可以预分配足够的内存空间，常用的方法是strings.Join函数，它会统计所有参数长度，并一次性完成内存分配操作，我们可以看一下在Go 1.10.1中它的源码：

// Join concatenates the elements of a to create a single string. The separator string
// sep is placed between elements in the resulting string.
func Join(a []string, sep string) string {
	switch len(a) {
	case 0:
		return ""
	case 1:
		return a[0]
	case 2:
		// Special case for common small values.
		// Remove if golang.org/issue/6714 is fixed
		return a[0] + sep + a[1]
	case 3:
		// Special case for common small values.
		// Remove if golang.org/issue/6714 is fixed
		return a[0] + sep + a[1] + sep + a[2]
	}
	n := len(sep) * (len(a) - 1)
	for i := 0; i < len(a); i++ {
		n += len(a[i])
	}

	b := make([]byte, n)
	bp := copy(b, a[0])
	for _, s := range a[1:] {
		bp += copy(b[bp:], sep)
		bp += copy(b[bp:], s)
	}
	return string(b)
}

　　我们可以这样使用：

func main() {
	str := make([]string, 1000)

	for i := 0; i < 1000; i++ {
		str[i] = "hello"
	}

	strings.Join(str, "-")
}

字符串拼接通常在堆上分配内存，这会对高并发应用造成较大影响，含有大量字符串对象要做垃圾回收，建议使用[]byte缓冲池，或在栈上自行拼装等方式来实现zero-garbage。

Unicode

　　类型rune专门用来存储Unicode码点，它也是int32的别名，使用单引号的字面量，其默认类型就是rune。 rune，byte，string之间是可以进行自由转换的。 　　字符串存储的是字节数组，不一定就是合法的UTF-8文本，我们可以人工截取一下：

func main() {
	s := "中国"
	s = string(s[0:1] + s[2:3])

	fmt.Println(s, utf8.ValidString(s))
}

输出：
�� false

　　len是不能正确返回Unicode字符数量的，我们可以通过RuneCountInString来返回准确的字符数量：

func main() {
	s := "中-国"

	fmt.Println(len(s), utf8.RuneCountInString(s))
}

输出：
7 3

数组

　　在Go中，元素类型相同，长度不同的数组不属于同一类型：

func main() {
	var d1 [3]int
	var d2 [2]int
	d1 = d2 // Cannot use d2 (type [2]int) as type [3]int in assignment
}

　　我们看几种初始化的方式：

func main() {
	var a [4]int	// 元素自动初始化为0
	b := [4]int{2, 5}	// 未提供初始值的元素自动初始化为0
	c := [4]int{5, 3: 10}	// 指定索引位置初始化
	d := [...]int{1, 2, 3}	// 编译器按照初始化值数量确定数组长度
	e := [...]int{10, 3: 100}	// 支持索引初始化，注意数组长度与此有关

	fmt.Println(a, b, c, d, e)
}

　　在定义多维数组时，仅第一维度允许使用“…”。

指针数组和数组指针

　　指针数组是指元素为指针类型的数组，数组指针是获取数组变量的地址。

func main() {
	x, y := 10, 20
	a := [...]*int{&x, &y}	// 元素为指针的指针数组
	p := &a		// 存储数组地址的指针

	fmt.Printf("%T, %v\n", a, a)
	fmt.Printf("%T, %v\n", p, p)
}

　　和C++一样，数组指针也可以直接用来操作元素：

func main() {
	a := [...]int{1, 2}
	p := &a

	p[1] += 10
	println(p[1] == a[1])
}

复制

　　C数组是变量隐式作为指针使用，而Go数组是值类型，赋值和传参都会复制整个数组数据。

func test(x [2]int) {
	fmt.Printf("x: %p, %v\n", &x, x)
}

func main() {
	a := [2]int{10, 20}

	var b [2]int
	b = a

	fmt.Printf("a: %p, %v\n", &a, a)
	fmt.Printf("b: %p, %v\n", &b, b)
	test(a)
}

输出：
a: 0xc420098010, [10 20]
b: 0xc420098020, [10 20]
x: 0xc420098070, [10 20]

　　我们可以发现，地址都不相同，如果不需要额外复制新的对象，可以改用指针或者切片。

切片

　　切片本身不是动态数组或数组指针，它内部通过指针引用底层数组，设定相关属性将数据读写操作限定在指定区域内，它本身是个只读对象，其工作机制类似数组指针的一种包装，它的结构大致如下：

type slice struct {
	array unsafe.Pointer
	len int
	cap int
}

　　属性cap表示切片所引用的数组片段的真实长度，len用于限定可读的写元素数量。可基于数组或者数组指针创建切片，以开始和结束索引位置确定所引用的数组片段，类似a[3:5]，是一个右半开区间，和Python不同，不支持反向索引。 　　我们来看一下切片的初始化，需要使用make函数或者显示初始语句：

func main() {
	s1 := make([]int, 3, 5)		// 指定len和cap，底层数组初始化为0
	s2 := make([]int, 3)		// 省略cap，和len相等
	s3 := []int{10, 20, 5: 30}	// 按初始化元素分配底层数组，并设置len和cap

	fmt.Println(s1, len(s1), cap(s1))
	fmt.Println(s2, len(s2), cap(s2))
	fmt.Println(s3, len(s3), cap(s3))
}

输出：
[0 0 0] 3 5
[0 0 0] 3 3
[10 20 0 0 0 30] 6 6

　　切片不支持比较操作，仅能判断是否为nil。 　　可获取元素的地址，但是不能像数组那样直接通过指针访问元素内容：

func main() {
	s := []int{10, 20, 5: 30}

	p := &s
	
	p[0] += 100	// Invalid operation: p[0] (type *[]int does not support indexing)
	(*p)[0] += 100	// *[]int 不支持索引操作，须先返回[]int对象
}

交错数组

　　如果元素类型也是切片，那么就可以实现类似交错数组（jagged array）功能，所谓的交错数组就是数组的数组，不同于二维数组，它的每个数组可以有不同的维度。

func main() {
	x := [][]int {
		{1, 2},
		{1, 2, 3},
		{1},
	}

	x[2] = append(x[2], 2, 3, 4)

	fmt.Println(x[2])
}

输出：
[1 2 3 4]

切片只是很小的结构体对象，用来代替数组传参可避免复制开销，make函数允许在运行期动态指定数组长度，绕开了数组类型必须使用编译期常量的限制，但是并非所有时候都适合用切片代替数组，因为切片底层数组可能会在堆上分配内存，而且小数组在栈上拷贝的消耗也未必比make代价要大。

reslice

　　将一个切片看作数据源，据此创建新切片对象，不能超出cap，但不受len限制。
　　通过数组创建新的切片对象，新建切片对象依旧指向底层数组，也就是说此修改对于所有关联切片可见。

func main()  {
	d := [...]int{0, 1, 3, 4, 5, 6, 7, 8}
	s1 := d[0:5]
	s2 := d[1:3]

	for i := range s2 {
		s2[i] += 1000
	}

	fmt.Println(d)
	fmt.Println(s1)
	fmt.Println(s2)
}

输出：
[0 1001 1003 4 5 6 7 8]
[0 1001 1003 4 5]
[1001 1003]

　　数据源如果是一个切片也是如此。

append

　　但是如果向切片尾部添加数据，返回的就是新的切片对象了，这点也比较容易理解，如超出cap限制，新切片对象会重新分配数组，这里超出切片cap限制而不是底层数组长度限制，因为cap可小于数组长度，新分配数组长度是原cap的2倍，但对于较大的切片，为了减少开销，或尝试扩容1/4。

copy

　　在两个切片对象间复制数据，允许指向同一底层数组，允许目标区间重叠，最终所复制长度以较短的切片长度（len）为准。

func main()  {
	s := []int{0, 1, 3, 4, 5, 6, 7, 8}

	s1 := s[5:8]
	n := copy(s[4:], s1)	// 同一底层数组
	fmt.Println(n, s)

	s2 := make([]int, 6)
	n = copy(s2, s)			// 不同底层数组
	fmt.Println(n, s2)
}

如果切片长时间引用大数组中很小的片段，建议ｉ新建独立切片，复制出所需数据，以便大数组内存可被及时回收。

字典

　　字典也就是哈希表，在Go中是语言内置类型，从运行时层面进行优化，可获得更高效的性能。
　　访问不存在的键值，默认返回零值，不会引发错误，但是推荐使用ok-idiom模式：

func main()  {
	m := map[string]int {
		"a": 1,
		"b": 2,
	}

	if v, ok := m["a"]; ok {
		println(v)
	}

	if v, ok := m["d"]; ok {
		println(v)
	}

}

　　字典是无序键值对集合，对字典进行迭代，每次返回的键值次序都不相同。函数len可以返回当前键值对数量，cap不接受字典类型。

not addressable

　　因为内存访问安全和哈希算法等缘故，字典被设计成”not addressable“的，不能直接修改value成员（结构或数组），看个例子：

func main()  {
	type user struct {
		name string
		age byte
	}
	
	m := map[int]user{
		1: {"A", 11},
		2: {"B", 32},
	}
	
	m[1].age += 1	// Cannot assign to 'm[1].age'
}

　　我们需要返回整个value，修改后设置字典键值，或者直接用指针类型。

func main()  {
	type user struct {
		name string
		age byte
	}

	m := map[int]user{
		1: {"A", 11},
		2: {"B", 32},
	}

	u := m[1]
	u.age += 1
	m[1] = u
	
	m2 := map[int]*user{
		1: &user{"C", 20},
	}
	
	m2[1].age++
}

安全

　　在迭代期间删除或新增键值是安全的。

性能

　　字典本身就是指针包装，传参时无须再次取地址。在创建时预先准备足够空间有助于提升性能，减少扩张时的内存分配和重新哈希操作。对于海量小对象，应直接用字典存储键值数据拷贝，而非指针。这有助于减少需要扫描的对象数量，大幅缩短垃圾回收的时间。字典不会收缩内存，适当换成新对象是有必要的。

结构体

　　结构体在初始化时，可以顺序初始化全部字段或者使用命名方式初始化指定字段。也可直接定义匿名结构类型变量，或用作字段类型，但因为缺乏类型标识，在作为字段类型时无法直接初始化：

func main()  {
	// 直接定义匿名结构变量
	u := struct {
		name string
		age byte
	}{
		name: "A",
		age: 11,
	}

	type file struct {
		name string
		// 定义匿名结构类型字段
		attr struct{
			owner int
			perm int
		}
	}

	f := file{
		name: "test.txt",
		// missing composite literals with incompatible types and values.
		/*attr: {
			owner: 1,
			perm: 0755,
		},*/
	}
	
	// 正确方式
	f.attr.owner = 1
	f.attr.perm = 0755
	
	fmt.Println(u, f)
}

　　可以使用指针直接操作结构字段，但不能是多级指针。

func main()  {
	type user struct {
		name string
		age int
	}
	
	p := &user{
		name: "A",
		age: 20,
	}
	
	p.name = "B"
	p.age++
	
	p2 := &p
	*p2.name = "C"	// Invalid indirect of 'p2.name' (type 'string') 
}

空结构

　　空结构struct{}是指没有字段的结构类型，无论是其自身还是作为数组类型，其长度都为0：

func main() {
	var a struct{}
	var b [100]struct{}

	println(unsafe.Sizeof(a), unsafe.Sizeof(b))
}

输出：
0 0

匿名字段

　　匿名字段是仅有类型的字段，没有字段名，从编译角度来看，这只是隐式地一类型名作为字段名字，可直接引用匿名字段的成员，但初始化时须当作独立字段。

func main() {
	f := file{
		name: "test.txt",
		// 显示初始化匿名字段
		attr: attr{
			perm: 0755,
		},
	}	
	
	f.perm = 0644		// 直接设置匿名字段成员
	println(f.perm)		// 直接读取匿名字段成员
}

　　不仅仅是结构体，出接口指针和多级指针以外的任何命名类型都可作为匿名字段。但是不能将基础类型和其指针类型同时嵌入，因为两者隐式名字相同，例如下面这种情况是错误的：

type data struct {
    *int
    int
}

　　可以像普通字段那样访问匿名字段，但当出现重名问题时，即匿名字段成员被外层同名字段遮蔽，那么必须使用显示字段名：

func main() {
	d := data{
		name: "data",
		file: file{"file"},
	}
	
	d.name = "test"
	d.file.name = "test"
}

　　Go不是传统意义上的面向对象语言，仅实现了最小面向对象机制，匿名嵌入不是继承，无法实现处理多态，虽然配合方法集，可用接口来实现一些类似操作，但其本质是完全不同的。

字段标签

　　字段标签（tag）不是注释，是用来对字段进行描述的元数据，它不属于数据成员，但却是类型的组成部分。在运行期可以通过反射来获取标签信息：

type user struct {
	name string `姓名`
	age int `年龄`
}

func main() {
	u := user{"Mike", 12}
	v := reflect.ValueOf(u)
	t := v.Type()

	for i, n := 0, t.NumField(); i < n; i++ {
		fmt.Printf("%s: %v\n", t.Field(i).Tag, v.Field(i))
	}
}

输出：
姓名: Mike
年龄: 12

内存布局

　　不管结构体包含多少字段，其内存总是一次性分配的，各字段在相邻的地址空间按定义顺序排列。当然对于引用类型，字符串和指针，结构内容中只包含其基本（头部）数据。除此之外，所有匿名字段成员也被包含在内。
　　在分配内存时。字段须做对齐处理，通常以所有字段最长的基础类型宽度为标准。比较特殊的是空结构字段，如果它是最后一个字段，那么编译器将它作为长度为1的类型做对齐处理，以便其地址不会越界，避免引发垃圾回收错误，否则认为它的长度为0。

func main() {
	v := struct {
		s1 struct{}
		a byte
		b [3]int
		s2 struct{}
	}{}

	fmt.Printf("%d, %d", unsafe.Alignof(v), unsafe.Sizeof(v))
}

输出：
8, 40
