GO 学习笔记（六）- 接口

引言

　　本文将作一些Go语言中涉及接口的一些笔记，这里只记录Go语言和其它语言不太一样的地方。

机制

　　Go接口实现机制很简单，只要目标类型方法集中包含接口声明的全部方法，就被视为实现了该接口，无需做显示声明，目标类型可以实现多个接口，接口也有一些限制：

  • 不能有字段
  • 不能定义自己的方法
  • 只能声明方法，不能实现
  • 可嵌入其他接口类型
type tester interface {
	test()
	string() string
}

type data struct {
	
}

func (*data) test()  {
	
}

func (data) string() string {
	return "Hello World!"
}

func main()  {
	var d data
	
	var t = &d
	t.test()
	println(t.string())
}

　　像匿名字段那样嵌入其他接口，目标类型方法集中必须包含嵌入接口方法在内的全部方法才算实现了该接口，嵌入其他类型接口，相当于将其声明的方法集导入，这要求不能有同名方法，因为不支持重载，如果嵌入自身或者循环嵌入，会导致递归错误。

type stringer interface {
	string() string
}

type tester interface {
	test()
	stringer
}

type data struct {

}

func (*data) test()  {

}

func (data) string() string {
	return "Hello World!"
}

func main()  {
	var d data

	var t = &d
	t.test()
	println(t.string())
}

　　超集接口变量可隐式的转换为子集，反之不可以。

type stringer interface {
	string() string
}

type tester interface {
	test()
	stringer
}

type data struct {

}

func (*data) test()  {

}

func (data) string() string {
	return "Hello World!"
}

func pp(s stringer) {
	println(s.string())
}

func main()  {
	var d data

	var t tester = &d
	pp(t)	// 隐式转换为子集接口

	var s stringer = t	// 显示转换为子集接口
	println(s.string())

	var tt tester = s	// stringer does not implement tester (missing test method)
}

　　支持匿名接口类型，可直接用于变量定义，或作为结构字段类型。

type data struct {}

func (data) string() string {
	return "Hello World!"
}

type node struct {
	// 匿名接口类型
	dataer interface{
		string() string
	}
}

func main()  {
	var t interface{
		string() string
	} = data{}
	
	n := node{
		dataer: t,
	}
	
	println(n.dataer.string())
}

空接口

　　如果接口没有任何方法声明，那么就是一个空接口interface{}，它的用途类似面向对象里的根类型Object，可被赋值成为任何类型的对象。接口变量默认值是nil，如果实现接口的类型支持，可做相等运算：

func main()  {
	var t1, t2 interface{}
	println(t1 == nil, t1 == t2)

	t1, t2 = 100, 100
	println(t1 == t2)

	t1, t2 = map[string]int{}, map[string]int{}
	println(t1 == t2)
}

输出：
true true
true
panic: runtime error: comparing uncomparable type map[string]int

类型转换

　　类型推断可将接口还原为原始类型，或用来判断是否实现了某个更具体的接口类型。

type data int

func (d data) String() string {
	return fmt.Sprintf("Data: %d", d)
}

func main()  {
	var d data = 15
	var x interface{} = d


	// 转换为更具体的接口类型
	if n, ok := x.(fmt.Stringer); ok {
		fmt.Println(n)
	}

	// 转换为原始类型
	if d2, ok := x.(data); ok {
		fmt.Println(d2)
	}

	e := x.(error)
	fmt.Println(e)
}

输出：
Data: 15
Data: 15
panic: interface conversion: main.data is not error: missing method Error

　　所以使用ok-idom模式比较好，即使出现了转换失败也不会引起panic，还可以用switch语句在多种类型间做出推断匹配，这样可以使空接口发挥更多空间。

func main()  {
	var x interface{} = func(x int) string {
		return fmt.Sprintf("d: %d", x)
	}

	switch v := x.(type) {
	case nil:
		println("nil")
	case *int:
		println(*v)
	case func(int) string:
		println(v(100))
	case fmt.Stringer:
		fmt.Println(v)
	default:
		println("unknown")
	}
}

输出：
d: 100

指定接口

　　我们可以用一个小技巧来确保类型实现了指定接口。

type x int

func init()  {
	var _ fmt.Stringer = x(0)
}

输出：
cannot use x(0) (type x) as type fmt.Stringer in assignment:
	x does not implement fmt.Stringer (missing String method)

　　我们也可以定义函数类型，让相同签名的函数自动实现某个接口。

type FuncString func() string

func (f FuncString) String() string {
	return f()
}

func main() {
	var t fmt.Stringer = FuncString(func() string {
		return "Hello"
	})
	
	fmt.Println(t)
}
