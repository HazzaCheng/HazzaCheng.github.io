Linux下避免rm误删

2018-05-11 阅读时长: 2 分钟
目录
  • 引言
  • 模拟回收站

版权声明：本文原创，转载请留意文尾，如有侵权请留言，谢谢

引言

　　在Linux下我们有的时候会用rm误删一些软件，导致无法恢复，这里介绍一种防止误删的操作。

模拟回收站

　　我们可以借鉴windows里回收站的思想，在本地目录建立一个隐藏文件夹.trash来保存删除的内容，我们是删除的内容实际上不是直接删除了，而是移入到了.trash中，我们来看一下实现的步骤。

  • 在home录下建立隐藏文件夹
~> mkdir ~/.trash
  • 创建remove.sh脚本，实现逻辑简单，就是垃圾文件移入.trash，然后在文件名上加上一个时间戳。
~> vim remove.sh

#!/bin/sh

TRASH_DIR="/home/hazzacheng/.trash"
for i in $*; do
    STAMP=`date +%s`
    fileName=`basename $i`
    mv $i $TRASH_DIR/$fileName.$STAMP
done
  • 修改.bashrc，添加一个alias
alias rm="sh /home/hazzacheng/Tool/remove.sh"

　　如果你需要sudo权限下也需要回收站的话，需要在root下的.bashrc也添加相应的alias。这里多说一句，如果使用fish shell的话，是没有办法使用bash的alias的，我们可以通过~/.config/fish/config.fish添加的相应的alias。

  • .trash需要控制容量，我们可以写一个脚本根据文件进入回收站的时间来删除，例如超过一个月就自动删除，也可以定时删除，也可以判断文件夹的容量，超过阈值，就执行清理操作，最简单可以每日定时执行清理，例如：
0 20 * * * rm -rf /home/hazzacheng/.trash/*
