引言

　　本文将作一些Go语言中涉及方法的一些笔记，这里只记录Go语言和其它语言不太一样的地方。

与函数的区别

　　方法是与对象实例绑定的特殊函数。在Go中，方法与函数定义语法的区别在于前者有前置实例接受参数（receiver），编译器以此确定方法所属类型。
　　可以为当前包，以及接口和指针以外的任何类型定义方法：

type N int

func (n N) toString() string {
	return fmt.Sprintf("%#x", n)
}

func main() {
	var n N = 25
	println(n.toString())
}

输出：
0x19

　　方法不支持重载，方法内部不引用实例，receiver参数名没有限制，可省略参数名，仅保留类型。
　　方法可看作特殊的函数，receiver的类型可以是基础类型或者指针类型，这关系到调用时对象是否被复制：

type N int

func (n N) value() {
	n++
	fmt.Printf("v: %p, %v\n", &n, n)
}

func (n *N) pointer() {
	*n++
	fmt.Printf("p: %p, %v\n", n, *n)
}

func main() {
	var n N = 25

	n.value()
	n.pointer()

	fmt.Printf("n: %p, %v\n", &n, n)
}

输出：
v: 0xc42001e0a8, 26     // receiver被复制了一份
p: 0xc42001e0a0, 26
n: 0xc42001e0a0, 26

　　可使用实例值或者指针调用方法，编译器会根据方法receiver类型自动在基础类型和指针类型间转换，但是不能用多级指针调用方法：

type N int

func (n N) value() {
	n++
	fmt.Printf("v: %p, %v\n", &n, n)
}

func (n *N) pointer() {
	*n++
	fmt.Printf("p: %p, %v\n", n, *n)
}

func main() {
	var n N = 25
	p := &n

	n.value()
	n.pointer()

	p.value()
	p.pointer()
}

输出：
v: 0xc42001e0a8, 26
p: 0xc42001e0a0, 26

v: 0xc42001e0d8, 27
p: 0xc42001e0a0, 27

　　receiver类型的选择也有点窍门：

  • 要修改实例状态，用*T
  • 大对象用*T，减少复制成本
  • 无需修改状态的小对象或固定值，用T
  • 引用类型，字符串，函数等指针包装对象，用Ｔ
  • 包含Mutex等同步字段，避免因复制造成锁操作无效，用*T

匿名字段

　　可以像字段成员那样访问匿名字段⽅方法，编译器负责查找。

type data struct {
	sync.Mutex
	buf [1024]byte
}

func main()  {
	d := data{}
	d.Lock()
defer d.Unlock()
}

　　对于上面d.Lock()编译会处理sync.(*Mutex).Lock()调用。
　　方法也会有同名遮蔽问题，利用这种特性可实现类似覆盖（override）:

type user struct {}

type manager struct {
	user
}

func (user) toString() string {
	return "user"
}

func (m manager) toString() string {
	return m.user.toString() + "--manager"
}

func main()  {
	var m manager

	println(m.toString())
	println(m.user.toString())
}

输出：
user--manager
user

　　尽管能直接访问匿名字段的成员和方法，但它们依然不属于继承关系，这一点需要理解。

方法集

　　每个类型都有与之关联的方法集，这决定它是否实现某个接口：

  • 类型T⽅方法集包含全部receiver T方法。
  • 类型*T⽅方法集包含全部receiver T + *T方法。
  • 匿名嵌入S，则T⽅方法集包含receiver S方法。
  • 匿名嵌入*S，则T方法集包含receiver S + *S方法。
  • 不管匿名嵌入S或*S，*T方法集总是包含S + *S⽅方法。

　　我们可以测试一下这些规则：

type S struct {

}

type T struct {
	S
}

func (S) ValS() {}
func (*S) PtrS() {}
func (T) ValT() {}
func (*T) PtrT() {}

func methodSet(a interface{})  {
	t := reflect.TypeOf(a)

	for i, n := 0, t.NumMethod(); i < n; i++ {
		m := t.Method(i)
		fmt.Println(m.Name, m.Type)
	}
}

type N int

func (n *N) test() {
	fmt.Printf("test.n: %p, %d\n", n, *n)
}

func main()  {
	var t T = T{}

	methodSet(t)
	fmt.Println("================================")
	methodSet(&t)
}

输出：
ValS func(main.T)
ValT func(main.T)
================================
PtrS func(*main.T)
PtrT func(*main.T)
ValS func(*main.T)
ValT func(*main.T)

　　结果符合我们的预期，但我们也注意到某些方法的receiver类型发生了改变，因为这些都是由编译器按照方法集所需自动生成的额外包装方法。

注意从Go1.7开始 The Method and NumMethod methods of Type and Value no longer return or count unexported methods.The Method and NumMethod methods of Type and Value no longer return or count unexported methods. 所以我们必须把方法都设置成exported，也就是首字母大写。

表达式

　　方法和函数一样，除直接调用外，还可赋值给变量，或作为参数传递，按照引用方式不同，可分为expression和value。

Method Expression

　　通过类型引用的expression会被还原成普通函数样式，receiver是第一参数，调用时须显式传参，T和*T均可，只要目标方法存在于给类型方法集中即可。

type N int

func (n N) test() {
	fmt.Printf("test.n: %p, %d\n", &n, n)
}

func main()  {
	var n N = 25
	fmt.Printf("main.n: %p, %d\n", &n, n)

	f1 := N.test	// func(n N)
	f1(n)

	f2 := (*N).test	// func(n *N)
	f2(&n)
}

输出：
main.n: 0xc42001c068, 25
test.n: 0xc42001c0a0, 25
test.n: 0xc42001c0b0, 25

Method Value

　　基于实例或指针引用的method value，参数签名不会改变，按照正常方式调用。当value被赋值给变量或者作为参数传递时，会立即计算并复制该方法的执行所需的receiver对象，与其绑定，以便在以后执行时能隐式传入receiver参数。

type N int

func (n N) test() {
	fmt.Printf("test.n: %p, %d\n", &n, n)
}

func main()  {
	var n N = 25
	p := &n

	n++
	f1 := n.test

	n++
	f2 := p.test

	n++
	fmt.Printf("main.n: %p, %v\n", p, n)

	f1()
	f2()
}

输出：
main.n: 0xc42009c010, 28
test.n: 0xc42009c028, 26
test.n: 0xc42009c038, 27

　　当method value作为参数时，会复制含receiver在内的整个mmethod value。

type N int

func (n N) test() {
	fmt.Printf("test.n: %p, %d\n", &n, n)
}

func call(m func())  {
	m()
}

func main()  {
	var n N = 25
	p := &n

	fmt.Printf("main.n: %p, %v\n", p, n)

	n++
	call(n.test)

	n++
	call(p.test)
}

输出：
main.n: 0xc42001c068, 25
test.n: 0xc42001c0a0, 26
test.n: 0xc42001c0b0, 27

　　如果目标方法的receiver是指针的话，那么仅仅复制指针。

type N int

func (n *N) test() {
	fmt.Printf("test.n: %p, %d\n", n, *n)
}

func main()  {
	var n N = 25
	p := &n


	n++
	f1 := n.test

	n++
	f2 := p.test

	n++
	fmt.Printf("main.n: %p, %v\n", p, n)

	f1()
	f2()
}

输出：
main.n: 0xc42001c068, 28
test.n: 0xc42001c068, 28
test.n: 0xc42001c068, 28
