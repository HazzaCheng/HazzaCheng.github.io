AutoML HPO 学习笔记（二）- Hyperopt 和 TPE

引言

　　Hyperopt[2] 是一个可以自动挑选模型和超参的 python 库，最近看了它的开发者在2011发表的原始论文[1]，Hyperopt挑选模型和参数主要利用了 random search 和 TPE 两种搜索方法，前者很简单，本文就不说了，这篇文章记录记录 TPE 的思想，它主要也是基于 GP 和 Bayes optimization 的。

SMBO

　　SMBO ，GP 和贝叶斯优化的具体知识就不说了，具体可以看看我这篇文章。引用论文里的伪代码，SMBO 的一个总体流程如下：

　　这里找 \(x^{*}\) 主要用的是EI：

\[ \mathrm{EI}_{y^{*}}(x):=\int_{-\infty}^{\infty} \max \left(y^{*}-y, 0\right) p_{M}(y | x) d y \]

　　然后再基于 GP 作为概率代理模型去不断建模迭代，得到我们最后最优的模型参数。

TPE

　　我们记参数空间为 \(\mathcal{X}\)，GP 是根据 \(p(y | x)\) 建模，而 TPE 是根据 \(p(x | y)\) 和 \(p(y)\) 进行建模。TPE 的全称是 Tree-structured Parzen Estimator Approach，为什么说有 tree 呢？TPE实际上是一 个graph-structured generative 的过程，它根据 \(p(x | y)\) 来实现这一 generative 的过程，我们记不同的 observations 为 \(\left\{x^{(1)}, \ldots, x^{(k)}\right\}\)，TPE 通过以下公式将 \(p(x | y)\) 变成两个概率密度函数：

\[ p(x | y)=\left\{\begin{array}{ll}{\ell(x)} & {\text { if } y<y^{*}} \\ {g(x)} & {\text { if } y \geq y^{*}}\end{array}\right. \]

　　其中 \(\ell(x)\) 是由满足 \(f\left(x^{(i)}\right) \lt y^{*}\) 的 \(\left\{x^{(i)}\right\}\) 所形成的概率密度函数，反之 \(g(x)\) 亦然。
　　GP 倾向于使用比较 aggressive 的 \(y^{*}\)，通常比 best observed loss 略小。而 TPE 相反，倾向于使用比 best observed loss 略大的 \(y^{*}\)，这样就有一些点可以去构造 \(\ell(x)\)。TPE 记 \(p\left(y<y^{*}\right)=\gamma\)，\(p(y)\) 使用的 model 不是必须的。
　　我们来改写下 EI 函数，将它用 \(p(y | x)\) 表示换成用 \(p(y) p(x | y)\)来表示：

\[ \mathrm{EI}_{y^{*}}(x)=\int_{-\infty}^{y^{*}}\left(y^{*}-y\right) p(y | x) d y=\int_{-\infty}^{y^{*}}\left(y^{*}-y\right) \frac{p(x | y) p(y)}{p(x)} d y \]

　　因为 \(\gamma=p\left(y<y^{*}\right)\)，可得：

\[ p(x)=\int_{\mathbb{R}} p(x | y) p(y) d y=\gamma \ell(x)+(1-\gamma) g(x) \]

　　进一步可得：

\[ \int_{-\infty}^{y^{*}}\left(y^{*}-y\right) p(x | y) p(y) d y=\ell(x) \int_{-\infty}^{y^{*}}\left(y^{*}-y\right) p(y) d y=\gamma y^{*} \ell(x)-\ell(x) \int_{-\infty}^{y^{*}} y p(y) d y \]

论文原文中最后一项漏写一个\(y\)，这里我给加上了。

　　那么可得 EI：

\[ E I_{y^{*}}(x)=\frac{\gamma y^{*} \ell(x)-\ell(x) \int_{-\infty}^{y^{*}} p(y) d y}{\gamma \ell(x)+(1-\gamma) g(x)} \propto\left(\gamma+\frac{g(x)}{\ell(x)}(1-\gamma)\right)^{-1} \]

　　通过它正比于的项，我们也可以看出要想得到比较大的 improvement，倾向于选择 \(\ell(x)\) 较大，\(g(x)\)较小的 \(x\)。
　　读完这篇论文我还是比较疑惑 TPE 里的 tree 到底是啥，查了一些资料才发现，tree 指的是参数空间是树形的，也就是参数空间里的一些参数存在依赖关系，一些参数的取值取决于其它参数的取值，就比如下面的例子，我们需要知道模型的 type 是什么才知道有哪些参数：

space = hp.choice('classifier_type', [
{
    'type': 'naive_bayes',
},
{
    'type': 'svm',
    'C': hp.lognormal('svm_C', 0, 1),
    'kernel': hp.choice('svm_kernel', [
        {'ktype': 'linear'},
        {'ktype': 'RBF', 'width': hp.lognormal('svm_rbf_width', 0, 1)},
        ]),
},
{
    'type': 'dtree',
    'criterion': hp.choice('dtree_criterion', ['gini', 'entropy']),
    'max_depth': hp.choice('dtree_max_depth',
        [None, hp.qlognormal('dtree_max_depth_int', 3, 1, 1)]),
    'min_samples_split': hp.qlognormal('dtree_min_samples_split', 2, 1, 1),
},
])

Parallel

　　在 TPE 中，会根据 \(\ell(x)\)的随机性选取多个 candidates 作为\(x^{*}\)，作为下一轮的迭代去并行评价。
