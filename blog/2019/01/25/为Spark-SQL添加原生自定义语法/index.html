为Spark SQL添加原生自定义语法

2019-01-25 阅读时长: 3 分钟

引言

　　最近有需要为Spark SQL添加原生自定义语法的需求，不是通过udf的方式，于是研究了一波，其实也没想象中的那么复杂，还是比较容易的。

Antlr4

　　在Spark 2.0之前，Spark SQL使用Scala Parser功能去解析SQL表达式，其解析类为org.apache.spark.sql.catalyst.SqlParserSpark，非常难理解，从2.x开始，Spark SQL使用Antlr 4来解析SQL表达式。
　　在spark-catalyst的pom文件里，我们可以看到它引入了相关的maven plugin：

<plugin>
        <groupId>org.antlr</groupId>
        <artifactId>antlr4-maven-plugin</artifactId>
        <executions>
          <execution>
            <goals>
              <goal>antlr4</goal>
            </goals>
          </execution>
        </executions>
        <configuration>
          <visitor>true</visitor>
          <sourceDirectory>../catalyst/src/main/antlr4</sourceDirectory>
        </configuration>
</plugin>

SqlBase.g4

　　antlr4需要相应的描述文件来定义语法，在Spark中位spark/sql/catalyst/src/main/antlr4/org/apache/spark/sql/catalyst/parser/SqlBase.g4，它里面根据antlr4定义了一些语法。
　　假设我们现在需要创建一个类似CREATE DIMENSION IF NOT EXISTS [dimension table name] ON TABLE [table name] AS [query statement]的语法，它在某个table上创建我们根据query定义的一个维表demension的操作，我们可以在SqlBase.g4里添加一些内容。
　　首先，我们在statement下定义语法：

| CREATE DIMENSION (IF NOT EXISTS)? dimensionTable=tableIdentifier
    ON TABLE sourceTable=tableIdentifier
    AS queryString=query                                           #createDimension

　　接着在nonReserved下添加DIMENSION：

nonReserved
    : SHOW | TABLES | COLUMNS | COLUMN | PARTITIONS | FUNCTIONS | DATABASES | DIMENSION

　　最后，定义DIMENSION对应你需要输入的内容：

DIMENSION: 'DIMENSION';

　　像前面pom文件里展示的一样，其中<goal>antlr4</goal>会在<phase>generate-sources</phase>生命周期内执行描述文件的解析，所以我们修改了SqlBase.g4后，需要重新maven编译，编译后会在target\generated-sources\antlr4下生成表达式解析的java文件：

SparkSqlParser

　　最后我们需要在SparkSqlParser下添加新的visit方法来解析我们的语句，之前target里的java文件已经自动帮我们生成了对象和方法，例如CreateDimensionContext和visitCreateDimension，我们只需要override就可以了：

  override def visitCreateDimension(ctx: CreateDimensionContext): LogicalPlan = withOrigin(ctx) {
    val deimensionTableIdentifier = visitTableIdentifier(ctx.dimensionTable)
    val sourceTableIdentifier = visitTableIdentifier(ctx.sourceTable)
    val ifNotExists = ctx.EXISTS != null
    val quertString = source(ctx.queryString)

    CreateDimensionTableCommand(deimensionTableIdentifier,
      sourceTableIdentifier,
      Some(quertString),
      ifNotExists)
  }

　　CreateDimensionTableCommand是个case class类，用来完成我创建维表的相关逻辑，这里就不展示了，这三步就可以保证你自定义一个spark sql语法了，总的来说还是挺简单的。
