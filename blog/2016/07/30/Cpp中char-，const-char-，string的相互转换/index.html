C++ 中char*，const char*，string的相互转换

引言

　　本文介绍 C++ 中 char*、const char* 和 string 的互换方法。

string 赋值给char*

使用stringstream进行转换

stringstream str;
str.clear();
char* ch = new char[1024];
string s = "Hello World!";
str << s;			// 将s的值放到stringstream
str >> ch;		// 将stringstream中的值导出到ch
cout << ch << endl;	// 输出：Hello World!

使用strcpy进行转换

string str = "abc";
char* ch;
const int len = str.length();
ch = new char[len+1];
strcpy(ch, str.c_str());

string 赋值给const char*

string str = "Hello World!";
const char* cstr = str.c_str();

const char* 赋值给string

const char* cstr = "Hello World!";
string s(cstr);

char*赋值给string

char* c = "Hello World!";
string str(c);

const char* 赋值给char*

const char* cps = "Hello World!";
char* pc = newchar[100];
strcpy(pc, cps);
