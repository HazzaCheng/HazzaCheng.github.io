01 从 EDA 到系统设计，新思科技收取哪几种钱？

核心问题：同一个客户为什么会付出不同性质的钱，而这些钱为何不能用同一个软件订阅倍数估值？

15% 的收入增长里，多少属于原有业务？

FY2025 收入 7,054.178，比 FY2024 的 6,127.436 增长 15.12%；同年 Ansys 从交割日起贡献 756.6。机械扣掉这笔并购收入，剩余 6,297.578，相对上年增长只有 2.78%。这个计算不是公司披露的严格同口径有机增速，因为还没有校正剥离和 FY2024 多出的一周，却已经足以证明：“增长 15%”和“原有业务增长 15%”不是同一句话。FY2025 10-K，MD&A

这组数字也说明不能把整个公司重新定性为增长停滞。FY2025 Design Automation 的调整后营业利润增至 2,213.526，而 Design IP 从 730.174 降至 419.325。收入加总遮住了利润引擎的分化。传统 EDA 仍有产品价值，Ansys 提供新增规模，IP 则承受中国政策、客户需求和自身产品路线的多重压力。估值首先应拆开这些变化。

读者容易带着三个错觉进入这家公司：它是只卖软件的订阅商；芯片销量增长就会等比例增加它的收入；有了 Ansys 就能立刻获得端到端设计平台的全部利润。下面逐项拆开。

第一种钱：研发团队按时间购买工具使用能力

一家芯片公司启动新设计，架构和 RTL 代码尚不能直接变成可制造芯片。设计必须经过综合、布局布线、时序收敛、功耗检查、验证和签核；其中不同阶段可能同时使用多家供应商的产品。新思提供 Fusion Compiler、PrimeTime、VCS 等工具以及配套支持。客户付钱买的是在既定工艺和性能目标下，把设计可靠推进到下一步的能力，产品只是这种能力的载体。

传统 EDA 的 Technology Subscription License，简称 TSL，一般覆盖两至三年。公司把许可与持续更新视为一个组合履约义务，在合同期内按期确认收入。晶圆厂规则、设计要求和软件功能不断变化，更新不是锦上添花，而是维持许可可用性的一部分。这使收入看起来平稳，也意味着本季确认的许多收入来自前期销售成果。收入确认政策

平稳不等于无周期。研发预算削减时，最先变化的是合同谈判、续约规模、FSA 选用和设计启动，报表收入可能滞后反映。一个低增长季度不自动说明护城河崩溃，一个高增长季度也不能证明新订单仍强。必须同时观察确认收入、合同资产、剩余履约义务与客户项目活跃度，而后者通常没有完整公开数据。

收费并非简单的“工程师人数乘单价”。客户谈的是工具组合、并行使用范围、期限、未来采购权和整体预算；越是大型客户，越可能用采购规模要求更灵活的用量与折扣。功能更强可以带来价值提取，但供应商不能假定客户节省的全部工时都会转为软件提价。最重要的经营变量是续约时的合同总价值和用量扩展，而非软件菜单上某个标价。

第二种钱：在交付时确认的硬件与 IP

验证大型芯片需要仿真、硬件辅助验证和原型系统。ZeBu、HAPS 等对应真实硬件交付，确认收入一般取决于控制权转移，维护服务再按期确认。硬件增加公司价值，却会带来存货、制造供应链、交货时间和批次波动。FY2026 Q3 存货为 479.129，高于 FY2025 年末的 365.190；因此不能把新思完全当作没有营运资金的纯软件模型。资产负债表与收入确认

Design IP 则是预先设计、可集成进入客户芯片的电路模块，包括接口、存储器、逻辑库和安全等。客户买入它，是为减少自己重做成熟模块的成本和风险。许可收入主要在交付或许可生效时确认，支持收入在服务期内确认；定制开发按进度确认；某些合同另有客户销售后产生的 royalty。它有复用优势，但客户的每一个新节点、新接口和新设计都可能需要工程工作，不是把同一文件无限复制就能维持竞争力。

尤其不能把新思 IP 等同于 Arm 的处理器指令集授权。产品组合和 royalty 比重不同，新思当季披露的销售提成收入规模，也不能用来推定整个 IP 分部都像单位出货收费平台。FY2026 前九个月销售型 royalty 为 89.8，且在各期存在波动；公司并未提供足以把所有 IP 逐项分成 upfront 和 royalty 的公开单位经济表。Note 9，剩余履约义务和 royalty

FY2026 年 6 月出售 Processor IP Solutions 后，原有 ARC 等业务边界再次变化。研究未来的应用优化 IP，需要看新产品和具体合同，不能继续把已出售处理器业务的技术、收入和估值全部保留在新思账上。前进到更高价值子系统，与卖掉原有处理器 IP 并不在逻辑上冲突，但它提高了研发和客户验证的执行要求。

第三种钱：仿真许可、维护与工程服务

Ansys 扩展的是物理世界的求解范围。结构、热、流体、电磁等问题，不止存在于芯片内部，还存在于封装、服务器、汽车和工业设备。客户希望在制造实物前识别设计缺陷，减少测试与返工。工具的价值来自求解器、模型、验证历史以及工程师的工作流程，而非一个统一的“仿真席位”。业务范围

S&A 软件虽也可以按期限订阅，确认方式却可能与 EDA TSL 不同：公司把部分许可和支持视为不同履约义务，许可 upfront 确认、支持按期确认。订阅不是会计上递延确认的同义词。直接比较新思和另一个 SaaS 公司的递延收入比率，很容易把业务模式差异误写成收入质量问题。

另一个影响可比性的变化发生在 FY2026 第二季。公司提高了对渠道定价、交付和终端维护的控制，将相关经销安排收入改按总额列报。总额列报可能同时放大收入和相关成本，而不按相同比例增加利润。因此，Ansys 产品组增长、公司总收入增长和最终股东现金增长，需要分别验证。本文不自行估计尚未完整拆出的总额法增量。MD&A，S&A 收入确认

只保留三个利润变量

第一个变量是客户为经验证的工具和签核能力愿意投入多少预算。它受先进设计数量、复杂度和项目价值驱动，而不是只看全球芯片销售额。一个更昂贵的芯片项目可以需要更多验证，即使总出货件数没明显增长。相反，客户整合项目或取消新芯片，可能削弱工具增量需求。

第二个变量是 IP 的研发投向能否对上客户设计窗口。接口速度、工艺节点、低功耗要求都在变化；产品迟一个设计周期，损失的可能不仅是一张订单，还包括后续衍生项目。FY2025 的利润下滑提示，研发投入金额本身不能证明资本配置有效，必须看到客户采用和毛利转化。

第三个变量是新增收入留下多少现金。Ansys 带来的渠道、销售和研发规模可以形成协同，也可能形成重复系统和组织摩擦；AI 算力带来新收费机会，同时带来新的供应商成本。利润率改善应拆成涨价与组合、真实效率、裁员、SBC 和会计变化，不能只看一条 non-GAAP 利润率曲线。

这三个变量之间存在制约。过度压缩研发会提升当期利润，却可能丢掉下一代工具的可信度；追求增长而授予大量股票会增加规模，却不保证每股价值；大客户扩展采购提升收入，又可能提高议价能力。好的研究应把制约写清，而不是给三个变量都填上向上箭头。

反方最有力的说法是：这些工具的确重要，但大客户知道其重要性，会尽量保留多供应商流程；Ansys 本来也是好资产，新思已经以现金和股份支付了其价值。投资者不能把“更加完整”自动翻译为“股东多赚”。这个反方将贯穿后续系列。

02 设计工具与半导体 IP，客户为什么难以迁移？

核心问题：工具可以替换，为什么一套已经跑通的设计流程仍有黏性？

最贵的不是许可，而是一次未经验证的替换

FY2025 Design Automation 的调整后营业利润率约 41.75%，IP 约 23.94%。两者都使用大量工程知识，但盈利表现相差很大。若“芯片公司不敢更换供应商”足以解释一切，就无法解释这段差距。黏性必须落实到产品、工艺、客户窗口和成本结构，不能当作整家公司不受竞争影响的护身符。分部数据

一个设计团队可以快速试用新工具，却未必愿意在关键流片前切换签核流程。风险不仅是新工具有错误，还包括不同工具对同一设计给出不同结果后，团队如何解释差异、重新标定约束、获得内部批准，以及谁对延迟负责。越接近制造和投产，替换越容易触发连锁验证。这是从客户决策机制推导的护城河，不是公司披露了某个固定迁移成本。

与此同时，新项目恰恰提供了替换入口。客户可以在新工艺、新模块或新团队中测试其他工具，避免对现有项目直接动刀。因此新思能在已跑通的环节获得稳定收入，却仍必须在下一代工具上赢。把旧项目锁定程度当成未来十年所有新增设计都归新思，属于外推错误。

竞争者不是一张“失败名单”

传统 EDA 的现实对手包括 Cadence、Siemens EDA，IP 还有多类专门供应商和客户自研，工程仿真又面对其他软件公司。它们不是已经被证明失败的挑战者。本文没有取得可核实、同口径的逐产品替换失败案例库，因此不编造“某公司挑战若干年全部失败”的名单，也不给未经核实的市场份额数字。竞争说明

更有解释力的是进入路径：成熟厂商可以先在单个流程环节取得优势，再通过接口与支持进入大客户。新创公司可能针对某一种算法或验证瓶颈。客户自研通常围绕自己最特殊的工作负载。国产替代在政策推动下获得试用机会。这些路径都不要求从第一天复制完整新思产品线。

这也让“拿一大笔钱能不能复制”需要分两层回答。复制整个产品组合、验证历史和全球支持网络很难；拿下一个新兴环节并非同样困难。如果利润池逐渐移到新环节，原有主导者即使没有丢掉旧收入，估值也可能下调。真正的防守要看新增研发是否跟上利润迁移，而不只看存量工具仍有人用。

客户迁不走什么？

第一层是可执行的设计约束与流程资产。工程师把工艺规则、时序约束、验证脚本、异常处理和设计方法组织成可反复使用的流程。公开数据格式和语言标准降低了交换成本，但不意味着不同求解器、优化路径和边界情况自动得到同一结果。数据可以导出，经过验证的工作方法未必可以原封不动搬走。

第二层是团队累积的判断能力。工具报错不只是屏幕上的文字，工程师需要知道什么时候该调整参数、什么时候应修改设计、什么时候是模型边界问题。熟悉的支持团队和历史问题库使项目推进更快。这个优势有经验积累成分，但也受核心人才流动影响；不能全部归结为不可转移的软件专利。

第三层是围绕晶圆工艺的验证关系。工艺设计套件和经过认证的工具流程，使客户能减少从设计到制造之间的不确定性。认证是一条具体的工艺、版本和应用链，不是一张允许厂商永远排除竞品的许可证。竞争者同样可以持续投入并获得认证，新思需要不断维护这些关系。

第四层是责任和时间。采购经理可以比较软件费用，项目负责人更关心失败成本与上市时间。客户支付的溢价有一部分来自供应商降低项目风险的能力。但这不是供应商无限提价的许可：当工具价格吞噬了过多项目预算，客户就会用替代流程、组合采购或自研来恢复谈判力量。

这四层优势相互强化，却不是互联网式用户网络效应。多一个客户通常不会自动让另一个客户的芯片设计获得直接收益；客户机密也限制数据自由聚合。更准确的描述是研发规模、验证经验和生态互补带来的反馈。把它写成无限扩张的平台网络效应，会给出过高的边际利润假设。

从时序签核到设计实现：价值在不同阶段流动

以逻辑设计为例，综合把较高层次的设计转换为门级表示；布局布线把逻辑落实为空间和连接；验证检查设计是否符合目标；签核为关键性能和制造可行性提供最终依据。公司各类工具覆盖其中多个步骤，客户仍可以组合竞品。这些步骤之间的相互影响，使完整流程集成有价值：前端选择可能改变后端功耗、面积和时序，后端信息又会要求前端修改。产品与标准

新思的优势是可以缩短多次来回的成本。风险则是集成让流程更复杂，也使客户担心对一家供应商依赖过深。年报明确支持行业标准、API 和与第三方的数据交换；开放互通既是客户采用的条件，也是竞争持续存在的通道。不能同时把“开放生态”当作增长理由，又把“客户完全出不去”当作估值理由。

工具品质最终要在客户目标下评价。更快不等于更好；若加速以牺牲功耗、面积或性能为代价，客户未必接受。PPA 指 power、performance、area，三者往往互相制约。很多营销案例用某一个设计和某一种基线展示改进，不能据此推算所有客户都能得到同样收益。本报告不引用未获得统一测试条件的“效率提升倍数”作为财务输入。

IP 的壁垒为什么更容易出现缺口？

一个成熟接口 IP 的价值，是把复杂协议和物理实现风险交给已经有经验的供应商。客户节省的不只是开发时间，还包括对工艺和兼容性的验证工作。新思可以将同一类知识服务多家客户，摊薄研发成本；成功设计又可能带来后续版本和支持需求。这是可复用知识的规模优势。

但复用必须跨越边界。不同节点的物理特性、接口速度、供电和封装条件会改变产品要求。新的设计窗口不接受一个已经错过时间表的“优秀旧版本”。客户也可能只购买特定模块，不把整个子系统交出去；大客户有能力内部开发最能形成差异化的部分。

FY2025 的 IP 经验特别有价值。年报把压力同时归因于中国出口控制、主要晶圆代工客户需求低于预期、以及若干路线和资源决策没有达到效果。这里包含公司可控制的问题，也包含外部问题。若将下降全部解释成政策，投资者会错过需要修复的组织执行；若把下降全解释成产品失去竞争力，也会忽略外部设计启动中断。FY2025 经营回顾

FY2026 Q3 IP 收入 473.851，调整后营业利润 125.392，同比均有恢复；但前九个月累计调整后利润为 302.170，低于上年的 363.084。新产品研发和退出旧业务可能先增加成本，再带来收入，因而单季利润率回升不能证明全部转型已经结束。最新分部附注

对应用优化 IP 的更高抱负，应检验三个问题：客户是否接受为更多系统功能付费；新思承担的定制责任是否同步增加；royalty 是否能在量产阶段补偿前期工程投入。大型合同证明客户需求，不能直接证明项目利润率，也不能在收入确认前把未来全部 royalty 资本化成确定价值。

过去五年的变化不能概括为单向变宽。系统级能力更完整，产品接口更多，进入大客户的机会扩大；另一方面，出口政策鼓励替代，客户采购集中度和 AI 自动化也会改变价值分配。由此形成的是一个更宽但更复杂的业务系统，其股东风险未必更低。

假设拥有 1,000 亿美元，能复制什么？

这个反向实验是思考工具，不是现实项目预算。巨额资金可以买人才、算力和部分软件资产，也可以通过价格吸引客户试用。难买的是跨多代工艺、许多设计与客户共同累积的信任。一个新供应商要让客户承担更换风险，需要在成本、速度或性能上提供足够补偿，不能只靠产品功能列表。

但若把问题改成“能否让新思的某些新增利润无法实现”，答案就更开放。客户自研 agent 可以压缩人工操作价值，另一家求解器可以夺走单个高增长环节，本地替代可以承接政策隔离市场，云平台可以提高算力分成。摧毁整家公司很难，与削弱新投资者的预期回报，是两个难度不同的目标。

这使当前价格的风险不同于公司生存风险。即使新思十年后仍是核心供应商，只要增速低于估值要求、SBC 高于预期或资本配置回报一般，买入者也可能获得普通甚至较差的收益。护城河保护经营的程度，大于它保护任何价格买入者的程度。

把一张续约单拆成三次谈判

第一次谈判发生在技术验证之前，客户决定是否值得试用。价格不是唯一障碍，工程支持、测试设计和与原流程兼容都可能消耗供应商资源。低价进入并不代表能留下足够利润，新思也要持续为试用和设计导入提供人员。若新产品销量增长伴随大量工程投入，毛利和交付成本会先告诉投资者质量如何。

第二次谈判发生在设计进入正式流程之后。采购希望用总合同控制费用，工程团队希望降低变更风险，供应商则希望把功能扩展转换成合同价值。三方目标并不相同。这使客户对新思的依赖，与客户是否同意付更高价格不能画等号；当项目预算受限时，客户可能接受较少用量、延长旧版本使用或推迟非关键功能。

第三次谈判发生在下一代设计启动时。此时旧项目中的锁定并未消失，但新项目有重新评估的窗口。供应商必须拿出新的工艺适用性、性能和支持，才能续上未来。把所有合同都写成“自动续费”会漏掉这一层。公开报表没有提供一张按产品、客户和节点划分的净留存率表，投资者无法从公司总收入反推每类产品的续约质量。

对 IP 也是一样。已量产项目的 royalty 可能继续，下一代芯片的许可选择仍可能改变；一份标准模块许可与一个深度定制子系统项目，包含的服务和风险不同。只有在复用比例提高、研发成本摊薄且客户持续采用时，大合同才会变成持续经济利润，而不是更大的工程负担。

如何区分护城河变深和报表暂时变好？

若利润率改善来自客户更广泛使用新工具，通常应能在多个维度看到一致变化：合同价值和收入增长、支持和交付成本可控、回款最终改善。若只看到裁员后的当期费用下降，尚不足以证明定价权提高。若只看到取得大合同而合同资产持续增加，也需要等待交付与现金。

若收入稳定来自旧合约逐期确认，短期利润不必马上体现新增订单恶化。相反，前期合同较弱也可能暂时压住收入，而新项目开始改善。研究需要保留这个滞后，而不是把本季股价与本季收入强行配成原因和结果。对新思，backlog 的构成和 FSA 的具体选用，比单看总额更接近新增工作能否兑现的问题。

这里不存在一个完全公开、可自动判定护城河的指标。企业可以通过大客户组合、合同期限和交付时点改变短期表现。合理做法是保持几条独立证据：产品能否在新节点上被采用、客户愿付的总价、保留研发和 SBC 后的利润、最终回款。它们一起改善，才比“管理层说客户反馈很好”更有证明力。

反向证据也应成组出现。一个大客户减少采购可能只是项目节奏；多个客户在不同产品线上降低采用、公司为维持收入加大折扣、技术支持负担上升，则更可能是经济护城河变弱。没有这样的证据，不能仅因股价下跌就宣判竞争失败；同样，没有真实采用与现金，不能仅因股价上涨就宣布竞争胜利。

五年与十年的观察方式

五年视角，最该观察的不是产品数量，而是先进设计项目中使用范围是否扩大、IP 恢复是否伴随利润和回款、Ansys 与 EDA 的联合能力是否产生可付费的独立价值。十年视角，则要问：设计交互方式变化后，底层求解和签核是否仍然稀缺？如果工具调用被 agent 接管，新思还能在执行层收取经济租金，还是只剩低价计算服务？

强的正方认为，操作界面可以变，制造约束与物理真实性不能消失，核心求解器反而会被更频繁调用。强的反方认为，客户会把新工具接口标准化，agent 更容易跨供应商调度，从而削弱一站式采购溢价。两者都说得通，关键证据将是合约结构、客户付费方式与扣除算力后的新增利润，而非发布会上 agent 的演示效果。

巴菲特式追问：十年后客户仍依赖这一类能力，并不等于十年后仍以相同比例向这家公司付钱。需要验证的，是可靠求解与工程责任能否继续成为收费瓶颈。

从芯片内部走到物理系统，联合价值在哪里？

高性能芯片的约束越来越跨越边界。芯片内部减少某处功耗，可能改变封装热分布；更高密度封装带来的散热和电磁问题，又可能限制系统性能。若设计团队在不同软件间反复转换模型、重新建立边界条件，就会增加迭代时间。把芯片设计与电磁、热、结构等求解连起来，存在明确的工程需求。

Ansys 的物理仿真能力使新思不必只在最后把设计交给外部工具。它有机会更早把系统约束反馈到芯片与封装设计。对汽车、工业和航空等用户，仿真也可以扩大客户面；这些用户不一定是传统 EDA 采购者，销售周期和渠道因而更加多样。业务与产品范围

但“覆盖得更广”与“已经一体化”之间有大量工作。不同模型的精度、版本、输入边界和数据管理必须一致；不同团队对结果负责的方式也不同。芯片设计部门与系统仿真部门的预算未必统一。工具可以有集成接口，客户仍然可能继续分别采购。联合产品的交付、被客户采用、产生付费、最终留存利润，是四个相继验证的阶段。

这笔交易也有防守性：若物理约束成为先进设计的核心瓶颈，缺少相应能力可能让传统 EDA 厂商在流程中处于不利位置。买入 Ansys 可以降低这种战略风险。但防守性价值不是现金流豁免条款；如果只是防止既有业务恶化，估值就应减少对额外交叉销售的想象。

联合产品的验证，要越过四道门

第一道门是技术可连通。两套软件交换输入输出，只能证明接口存在；模型精度、求解边界、版本和误差是否可控，还需要客户在真实设计中验证。演示可以选取理想案例，商业项目却要覆盖异常和失败条件。集成路线图值得跟踪，但不直接等于客户的关键流程已经迁移。

第二道门是工作流可承担责任。芯片、封装和系统团队需要在同一组约束下作决定；如果结果不同，谁更新模型、谁批准、谁签核？企业采购的不仅是算式，更是可审查、可追溯和可交付的工程过程。新思拥有更多工具后，必须让客户的协作成本下降，否则客户可能继续选择熟悉的分立流程。

第三道门是预算可兑现。有的集成功能会被纳入原许可，有的能够独立收费，有的通过更多用量收费。只有在知道客户支付方式后，才可能估计交叉销售价值。即使客户愿意多买，也可能要求原有合同降价作为交换。把新增产品销售额全部当新增利润，会忽略组合采购的相互影响。

第四道门才是股东经济回报。新增收入扣掉工程支持、外部计算、销售费用、人才留存和股权奖励后，是否形成高于单独运营的现金？如果可以，交易价值不必等到商誉减值测试才被看见。如果不能，利润率指标即使改善，也可能是费用分类、剥离和短期压缩投入共同形成。

为什么不能给“并购后 ROIC”一个漂亮答案？

收购把原来没有体现在新思账面的求解器、客户关系和未来协同，以数百亿美元的资本代价记上表；旧新思的研发则大量在历史年度费用化。两种来源的知识资产在资产负债表中不对称。用合并后的某个 GAAP NOPAT 除以账面资本，既受摊销影响，也受资本基数变化影响；数值下降不能单独证明工具失效。

反过来，剔掉所有商誉，再拿调整后利润计算很高的 ROIC，也会把股东实际支付的收购成本抹掉。评价 Ansys 交易，应保留收购价格和融资代价，跟踪可归属新增现金；评价日常新增设备和营运资本，则可以看费用化研发之后的表内资本效率。两类问题的分母不同，不能把日常资本效率用来证明巨额收购的回报已经很好。

因此，下一篇和终章分别使用不同工具：现金桥看已发生资金流，正常化桥看持续经营能力，DCF 用明确的新增资本假设约束未来增长。它们没有给出一个已核实的并购 ROIC。若未来联合销售、经营现金和每股权益持续改善，再逐步验证收购回报，比现在给一个小数点后的漂亮数更可靠。

一个失败但不戏剧化的结局同样值得保留：Ansys 产品仍优秀，客户仍在使用，公司也有利润，只是协同不足以补偿控制权价格和融资成本。这样的交易不一定带来业务危机，却会拖累多年股东回报。把风险只写成“整合彻底失败”会遗漏更常见、也更难及时察觉的普通低回报。

资本配置：先问股东的每一美元

融资结构把原本净现金、轻资产的公司变成有显著净债务的合并企业。借款和股份都不是坏工具，但它们改变了投资者持有的资产：以前主要押注工具业务持续增长，现在还押注并购回报、整合执行和债务安排。公司已偿还定期贷款，是正面结果；其中一部分能力来自出售资产和 NVIDIA 增发融资，不能全算作并购协同现金。

对这笔交易的初步评价应是“战略逻辑成立，经济回报待验证”。如果只有不做交易可能失去位置的恐惧，却没有可观测的增量现金，股东只能承担更复杂的风险。反过来，如果系统联合设计能增加新预算、降低销售服务成本，并让更多收入转成每股现金，Ansys 的价值不必靠会计商誉证明。

04 AI 与系统复杂度，增长会流向谁的利润？

核心问题：需求扩大和工程自动化同时发生时，哪部分新增价值可以归属新思股东？

2027 的 15% 增长已经成为公开目标

2026-09-30 投资者日，公司给出 FY2027 收入 11,100–11,200、中点 11,150，non-GAAP 营业利润率约 44%，non-GAAP EPS 19.04–19.12、中点 19.08。更长期的 FY2026–FY2030 目标为公司收入约 15% CAGR，EDA 13% 以上、S&A 10% 以上、IP 17% 以上，FY2030 non-GAAP 营业利润率约 50%。这些是管理层目标，不是已完成增长。投资者日原文

这意味着仅仅论证“AI 带来更多芯片”已经不足以支持买入。市场可以读取同一份增长框架。真正影响回报的是目标能否兑现、兑现中股东承担多少成本，以及价格已经付出了多少。增长叙事越广泛，越需要找出可能把它变成普通收益的环节。

先分清两条不同的 AI 需求链

第一条是为 AI 设计芯片。更多计算需求推动专用芯片、高带宽接口、先进封装、低功耗和系统散热等设计问题。新思出售工具和 IP 来帮助客户解决问题。如果客户研发预算增加，且软件支出与项目规模一起扩展，这条链有望增加收入。它的驱动因子是设计活动，不是投资新闻里的 GPU 资本开支总额。

第二条是用 AI 帮助设计。AI 可以组织流程、探索参数、调用工具、解释结果，缩短工程师操作和试验时间。它既可能增加尝试次数，也可能降低客户愿意为传统操作流程支付的价格。新思必须把效率提升转成可付费功能、额外使用量或结果价值，而不是只展示更短的运行演示。

两条链不能简单相加成两倍增长。若客户用效率提升吸收新增工作，工具用量未必增加；若更高复杂度要求更多搜索，新增调用又可能抵消单次效率改进。财务结果取决于客户项目数量、每项目计算与许可消费、公司分成和新增成本四个环节。

GPT-Synopsys 让商业模式问题变得具体

9 月 30 日公司与 OpenAI 宣布多年合作，开发面向芯片设计的 GPT-Synopsys。原文描述模型可使用新思 EDA 工具执行工作流，agent 运行工具、解读结果并迭代，由工程师审阅。服务拟捆绑计算、模型与许可，采用收入分享框架，运行于 OpenAI 托管基础设施。协议已经宣布，规模化收入和分成比例尚未披露。合作原文

这有利于验证“模型与物理真实性需要结合”的正方逻辑：通用模型生成一个候选设计，不等于设计经过制造约束和签核；工具提供结果验证。新思不必独占最强通用模型，也可能在执行和验证层收费。因此，模型能力进步未必绕开 EDA，可能增加对 EDA 的调用。

但分成结构也暴露了反方逻辑。捆绑服务收入增长时，计算、模型和渠道需要被支付。若新增收入中相当部分流向合作方，新思的现金增量小于账面销售增量。若客户平台掌握最终调度权，新思可能在底层被按调用比较价格。没有公开分成比例和单位成本，无法把这项合作直接换成某个净利润预测。

“客户数据不用于模型训练”等承诺是采用条件，不能被误读为数据完全没有治理成本。芯片设计涉及商业秘密、访问权限和审计要求，客户可能偏好本地或自己控制的工作流。公司同时支持完整平台、自有 agent 和客户平台对接，说明市场不只存在一种统一购买方式。多种路径扩大覆盖，也使货币化更难用单一席位模型描述。

专用硅与 AOIP：更高合同额后面有什么？

公司在投资者日提出 application-optimized IP，简称 AOIP，向针对特定负载和系统的子系统及平台扩展。它试图从标准接口供应商进一步参与客户架构与功能优化，以许可和后续使用相关收入取得更多价值。Amazon 合作被公司作为新模式早期采用的例子。投资者日，Silicon IP 部分

可得 Reuters 报道称 Amazon 多年 IP 协议超过 10 亿美元，但本报告未取得完整合同，也没有每年的交付、验收、royalty 与云采购分项。因而不把总合同额除以任意年数后加进模型，更不在公司已经发布的收入目标之外机械再加一笔。双方还存在云与工程合作，合作金额不是单向、当期、无成本的新增现金。Reuters 对协议的报道

从机制看，更大功能范围可以提高每个设计赢单的金额，也可能把新思从标准模块竞争带向工程交付竞争。如果定制成分上升，前期研发、项目管理和支持负担会增加；如果后续 royalty 才有主要回报，量产时间和客户最终销量又成为风险。收入增长可能先于利润，也可能晚于研发支出。

这条路线需要避免两个错误类比：不能因为有 royalty 就直接套用整个 Arm 的经济模型，也不能因为定制工作较多就把它全部当作低利润外包。正确的问题是标准化复用和客户专属工程各占多少、能否跨客户复用、失败项目由谁承担。公开信息尚不足以给出精确答案，所以模型用较宽的 IP 利润率情景处理。

系统仿真：效率提升可能扩大需求，也可能压价

在热、电磁、结构等仿真中，更多计算能力可使过去因成本而简化的模型变得可用，客户可能把更多产品和更多设计点纳入仿真。Ansys 的价值是提供经过验证的求解与工程工作流，这使“AI 能生成设计”与“能预测真实物理行为”之间仍有收费空间。

NVIDIA 2025-12-01 的合作公告涉及 CUDA 加速、agentic 与 physical AI、数字孪生，并伴随 20 亿美元入股。它表明新思正在适配计算平台变化，而不是只等待 CPU 软件自然增长。但是投资不是产品销售，入股价格也不构成股票底价；融资能改善债务安排，却没有替股东证明合作项目回报。NVIDIA 公告

加速后的需求反弹不能预先假定。工程团队预算有限，跑得更快有时意味着同样预算完成更多设计，有时意味着减少所需许可或算力。若客户坚持按结果或项目采购，供应商需要证明每个项目的价值增加。投资者要观察扣除外部计算费用后的利润，不能仅观察作业次数。

用预算约束检验“越快，需求越多”

设一个不代表真实客户的机制例子：工程团队的年度预算固定，软件与计算占用其中一部分。单次仿真变快后，它可以增加候选设计，也可以保持原有设计次数并缩减资源。前一种选择增加技术使用，后一种选择保留成本节约；两种都符合客户理性，只有前者更直接支持按用量收费。因此，用效率提高推断需求必然增加，缺了一步预算和回报判断。

如果更多候选方案提高最终芯片性能，客户可能愿意继续购买计算；如果新增方案带来的收益递减，调用量就会遇到上限。供应商需要寻找的是愿意为更多探索付钱的工程场景，而不是无限增长的搜索次数。能稳定提高上市速度或降低验证失败风险的场景，通常比仅减少一次点击更有收费基础，但本报告没有客户级 ROI 数据来给各场景排序。

收费方式也会改变成本传导。按席位收费时，自动化可能降低操作人数；按使用量收费时，公司与客户都要管理无效调用；按项目或结果收费时，供应商可能承担更多交付风险。订阅和消费混合可以扩大选择，却不能消除这些取舍。投资者应把合同结构变化与利润率一起看，避免只在用量增加时采用消费叙事、用量减少时又改用订阅稳定叙事。

三个可用的证伪实验

第一个实验，是找相似客户群里收入与成本是否同步改善。如果 AI 产品采用扩大，而研发、支持和外部算力增长更快，短期商业化可能尚不成熟。没有成本分项时，可以用全公司扣 SBC 后现金做下限检查，但不能把全公司现金改善全部归给 AI，因为税务、并购和收款节奏同样影响。

第二个实验，是区分联合产品带来的新预算与旧合同换名字。若客户原本购买新思与 Ansys 的多个产品，整合后只是改成一个套餐，订单总额扩大未必显著；若进入原本未覆盖的工程团队、获得新的设计项目，才更接近交叉销售。公开案例通常缺乏原合同基线，本报告因此不按案例数量估计协同收入。

第三个实验，是检验客户是否仍保留工具选择权。GPT-Synopsys 原文强调与客户 agent 环境互通，这可以促进采用，也说明单一平台的排他锁定并非既定事实。若底层可信工具持续被调用，新思仍可能受益；若工具在调度层变成可随时替换的标准件，流程整合带来的溢价就需要重新估计。

这些实验不是要求公司每季披露全部商业秘密，而是为研究设置边界：在没有足够证据时，先不给尚未证明的利润加估值。等证据出现再上调现金假设，可能付出更高买价，却减少把产品前景误当股东回报的风险。不同投资者可选择不同证据门槛，但应承认门槛改变了自己承担的风险。

聪明的非买家会怎样反驳？

他可以承认所有工程趋势，再说：公司需要更多人才和算力才能服务更复杂的项目；客户也拥有更强的采购和 AI 能力；Ansys 的规模是通过支付巨额对价买来的；non-GAAP 利润把持续 SBC 排除后显得更漂亮。即使 FY2027 指引兑现，按扣 SBC 后正常化收益计算的倍数也明显高于屏幕上约 24.5 倍的调整后 EPS 倍数。

这不是否认增长，而是要求增长落到每股可分配收益。若公司未来几年维持很高的每股现金增长，非买家会付出机会成本；若新增收入主要用于补偿股权奖励和整合成本，等待就有价值。两种方向都能通过数据逐渐分辨，无须先设一个“AI 成功概率”来制造精确感。

最可能的分析错误，是把工程复杂度增加直接翻译为新思净利润率扩大。复杂度同时增加客户需求与供应商工作量，只有标准化程度、定价权与规模效率超过新增成本时，利润率才会提升。44% 和 50% 的目标应成为检验这条机制的尺子，而不是把尺子本身当作证据。

李录式追问：这一轮技术进步创造了更大的工程价值，其中多少由客户、算力供应商、模型公司和设计软件分别取得？只有定位到利润归属，时代趋势才进入估值。

24.51 倍与 31.34 倍，都是同一个报价

以 467.61 美元除以公司 FY2027 non-GAAP EPS 中点 19.08，得到 24.51 倍；除以第 05 篇扣 SBC 后正常化 EPS 代理 14.92，得到约 31.34 倍。差别不是数学技巧，而是把持续股权劳动成本算不算成本。再用 TTM GAAP 总净利，则参考股权价值/净利为 83.24 倍，含摊销、处置等影响，不是最适合独立判断持续盈利的分母。

现金折现：把增长需要的钱先留下

DCF 使用无杠杆、扣 SBC 的正常化 NOPAT，避免在现金流中扣利息后又减净债务。以 FY2027 为第一年，FY2027–FY2036 共十期；各年现金按年末折现至研究基准附近，简化忽略财政年末与研究日的微小日历差。第一年利润基数为假设，后九年按情景增长，不是十年已知利润。

模型规则写在正文，方便读者推翻：

  • 高增长阶段 FCFF = NOPAT ×（1−增长率 / 60%）。60% 是费用化研发之后、表内新增营运资本与固定资本的增量回报假设，不是收购 Ansys 全部资本的 ROIC，也不是公司披露值。这样避免对已在利润中扣除的研发再资本化扣一次。
  • 终值 FCFF = 第十年 NOPAT ×（1+g）×（1−g / 稳态 ROIC）。终值企业价值 = 终值 FCFF /（r−g）。相当于用永续增长和留存需求导出的终值 NOPAT 倍数，而非随意拿同行倍数退出。
  • 企业价值为十期 FCFF 与终值的现值之和，再减一次净债务 6,429.691，除以 191.636646 百万股；现金只通过净债务桥计入一次。
  • USD 资本成本 r 基准 10%，敏感性 9%、11%。它是长期要求回报假设，约对应 4%–5% 的长期无风险基底加 5%–6% 风险补偿的范围判断；没有把工具内置利率当作研究日已核实国债报价，也不使用某个精确市场 beta 假装客观。
  • 出口与整合风险进入经营情景，不额外藏进折现率；战争导致不可交易、严重知识产权失效等离散尾部未作可靠量化。

反向估值：现价要求利润跑多快？

固定 FY2027 NOPAT 3,226.700、r=10%、g=3%、稳态 ROIC 25%、高增长期表内增量回报 60%，反解参考 EV 96,040.903，所需后续九年 NOPAT CAGR 约 17.29%。这不是市场真实持有的一张统一预测，而是本模型下支持现价的一个等价要求。

17.29% 不必靠收入也增长同样速度：利润率提高可以让利润快于收入。但初始利润已经用了 FY2027 44% non-GAAP 框架并恢复 SBC，不能再把同一年的利润率扩张当作免费额外好处。若相信 2030 年的效率目标和 IP 新模式，此要求可能实现；若只愿意承诺行业持续增长而不愿押注执行幅度，现价就缺乏缓冲。

另一条支持现价的路径是更低要求回报、更高长期资本效率或更慢的稳态降速。但这些也都是投资者承担的假设。用“市场一直给高倍数”无法消除它们；投资者应明确自己是在押增长、资本效率，还是未来仍有人愿意支付更高倍数。

为什么 SOTP 与 DCF 不同？

基准 SOTP 472.04，基准 DCF 332.52。两者差距不是让读者随意挑一个，而是暴露判断。SOTP 给 EDA 28 倍税前经济 EBITA，隐含较长的高增长、较强现金转换和优质业务溢价；DCF 在十年后将增长降到 3%，对稳态再投资作约束。SOTP 更贴近市场常见的优质软件定价，DCF 更强调终值纪律。

因此本文用 DCF 建安全边际，用 SOTP 理解市场解释。不能给两者各 50% 权重求一个“公允值”，那会隐藏分歧。当前价格接近基准 SOTP，却显著高于基准 DCF；要新增投资，就需要独立相信长期执行强于保守模型，或者等价格降低。
